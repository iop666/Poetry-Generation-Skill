# Poetry Generation Skill · 中文诗词文献与格律研究仓库

本仓库是一个**文献资料研究项目**，不是已发布、可直接安装使用的 Agent Skill。

当前实际状态：

- **Phase 0–2 进行中**：文献调查、阅读记录、作品数据库治理。
- **Phase 3–7 未授权或冻结**：知识体系提取、引擎深化、创作体系、模型能力验证、Skill 封装均**尚未开始**。
- 格律引擎是**冻结的研究原型**，可运行、有测试，但存在已知缺陷（见下文「已知缺陷」）。

### 如何接入本地数据库

```bash
# 数据库应放在（或软链到）：
poetry-database/database/poetry.db

# 指定其它路径：
python3 poetry-database/tools/r2_15_tests.py --db /path/to/poetry.db
# 或
POETRY_DB=/path/to/poetry.db python3 poetry-database/tools/r2_15_tests.py
```

没有数据库时，测试中的 `B` 组会标 `NOT RUN`，不会被误报为「数据库丢失」。

## 能做什么（已实现且可运行）

```bash
cd 诗词格律引擎

# 校验一首诗：判体式、逐字平仄、粘对、押韵、孤平、三平调、重字
python3 engine/gedou.py --title "秋山" \
  --text "山色苍茫暮雨收，寒烟一带过汀洲。归鸿不解人间意，犹向斜阳万里游。"

# 校验一首词
python3 engine/gedou.py --cipai 浣溪沙 --ci "一曲离歌送客舟……"

# 独立测试集（33 例）与验收题（6 题）
python3 engine/run_tests.py
python3 engine/run_acceptance.py
```

判定码只有四种：`合格` / `待确认` / `违律` / `不适用`。读音未定的位置一律输出 `UNKNOWN`，不为好看而猜音。

## 已知缺陷（不修，等 Phase 4 授权）

1. **浣溪沙薛昭蕴体**：引擎先按韩偓正体判首句违律，再在备注说「可能是薛昭蕴体、未收录其谱」——两结论矛盾。`tests/06_cipai.json` 的 C05 期望值固定为「违律」，等于用测试保护了错误行为。
2. **相见欢**：`CI_PATTERNS` 声明了 `仄韵位: [4,5]`，但 `check_ci()` 只处理 `韵位`，未执行仄韵检查；统计里也没有体现这部分 `NOT_CHECKED`。

33/33 通过**不代表**上述两条已解决。
