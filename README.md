# Poetry Generation Skill · 中文诗词创作与格律助手

一套面向 AI Agent 的**中文诗词创作技能**：让模型不再只靠语感"空转"，而是站在一套可查、可验、可复现的知识体系上写诗填词。

核心思路：**先建资料、再建规则、最后才谈创作**。整个项目分三层——文献与作品数据库（原料）→ 格律审查引擎（规则）→ 创作技能（产出），每一层的结论都能回溯到上一层。

---

## 它能做什么

| 能力 | 说明 |
|---|---|
| **创作** | 按《唐诗三百首》体例创作五绝 / 七绝 / 五律 / 七律 / 古体 / 乐府，可附注释、语译、赏析 |
| **格律自检** | 自动判体式、逐字平仄、失对失粘、押韵、孤平、三平调、三仄尾、重字、对仗粗检 |
| **词牌校验** | 词牌谱校验（已接入浣溪沙等）、词林正韵十九部查部 |
| **文献检索** | 9 万首作品按作者 / 体裁 / 词牌 / 正文检索，查来源许可与朝代覆盖 |

## 三个组成部分

### 1. 创作技能 `tang-poetry-composer`

蒸馏自《唐诗三百首全解（蘅塘退士 / 孙洙 编）》，把传统格律常识与"全解"体例转成一套可执行的创作流程。

- **体裁**：五古、七古、七言乐府、五律、七律、五绝、七绝（近体重格律，古体重气韵章法）
- **格律三要素**：平仄（含入声字表）、对与粘（"一三五不论，二四六分明"）、押韵
- **禁例**：孤平须救、三平调禁止、三仄尾尽量避免
- 内置一键格律自检脚本 `check_all.py`

### 2. 格律审查引擎（v2）

可运行的规则层：知识库（规则 + 韵书 + 作品）＋ 格律引擎（可判定部分）＋ 33 例独立测试集（样本先于结论存在）。

四种判定码：

| 判定 | 含义 |
|---|---|
| `合格` | 全部位置读音确定且合律 |
| `待确认` | 未发现违律，但有读音 / 韵部无法确定的位置（逐条列出） |
| `违律` | 有确定违律 |
| `不适用` | 非近体（如仄韵古体），不套近体谱 |

> `待确认` 不等于合格——引擎拒绝为读音未定的字臆选读音，这类位置一律输出 `UNKNOWN`。

### 3. 诗词文献与作品基础数据库 `poetry-database`

"先建资料"的第一层：原始文献层 + 结构化数据层，不含知识规则、不含格律引擎、不含文学评价。

| 指标 | 数值 |
|---|---|
| 作品记录 | 90,279（去重后 89,269） |
| 作者 | 5,286 |
| 采集来源 | 128（全部标注许可与可靠性） |
| 公版文献 | 25 种 |
| 体裁 | 11 类：五律 / 七律 / 五绝 / 七绝 / 五排 / 七排 / 古体 / 四言 / 楚辞 / 词 / 曲 |
| 数据库 | SQLite，约 95 MB，7 张表 |

## 快速开始

```bash
# 校验一首诗（自动判体式、逐字平仄、粘对、押韵、孤平、三平调、重字、对仗粗检）
python3 engine/gedou.py --title "秋山" \
  --text "山色苍茫暮雨收，寒烟一带过汀洲。归鸿不解人间意，犹向斜阳万里游。"

# 校验一首词
python3 engine/gedou.py --cipai 浣溪沙 --title "秋江送别" \
  --ci "一曲离歌送客舟，西风落叶满江秋，寒烟衰草锁汀洲。别后相思何处寄，楚天无际两悠悠，孤帆影没暮潮流。"

# 跑独立测试集（33 例）与六道验收题
python3 engine/run_tests.py
python3 engine/run_acceptance.py

# 检索作品库
python3 tools/query.py author 杜甫 --limit 5
python3 tools/query.py cipai 声声慢 --limit 3
python3 tools/query.py search 枯藤老树
```

退出码：`0` = 未发现明确违律，`2` = 存在违律（便于接入 CI / 批处理）。

依赖：Python 3.9+；引擎本身零第三方依赖，只读本地 JSON。仅韵表重建脚本需要 `opencc-python-reimplemented`（繁简转写，一次性）。

## 能力边界（如实列出）

| 能判 | 不判 / 需人工复核 |
|---|---|
| 出律（固定位：七言 2/4/6/7 字，五言 2/4/5 字） | 多音字的义项定音（无表即 `UNKNOWN`） |
| 失对、失粘 | 借邻韵、撞韵 |
| 落韵 / 出韵、白脚平收 | 半韵字的词韵归属 |
| 孤平（仅两平相连型平收句）、三平调、三仄尾 | 仄韵词牌的谱 |
| 重字、句式字数、词牌谱、古体 / 仄韵体识别 | 对仗是否成立、工拙；文学性评分 |

已知局限：多音字不消歧；词林正韵缺字级归属（半韵 692 字报 `UNKNOWN`）；词牌仅 3 个且无仄韵词牌；平韵古体不能识别；韵书来源未核验；语料来自 chinese-poetry，存在错字，**只能统计、不能引用**，引用前必须核印本。

- 作品语料源自 chinese-poetry（MIT），原文公有领域；文献转录源自维基文库（CC BY-SA 4.0）。
- 本技能与脚本：MIT。
- 数据库为多源并列，**没有校定本**；作者归属有争议处（如《登鹳雀楼》朱斌 / 王之涣并存）由文献学决定，程序不裁决。
