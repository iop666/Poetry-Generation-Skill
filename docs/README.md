# 诗词格律引擎 · 项目说明

按原方案「不要让 AI 空转，要让它有知识体系」的思路做的一个**可运行**的诗词写作辅助系统：
知识库（规则 + 韵书 + 作品）＋ 格律审查引擎（可判定部分）＋ 六道验收题的执行记录。

## 快速开始

```bash
cd 诗词格律引擎

# 校验一首诗（自动判体式、逐字平仄、粘对、押韵、孤平、三平调、重字、对仗粗检）
python3 engine/gedou.py --title "秋山" \
  --text "山色苍茫暮雨收，寒烟一带过汀洲。归鸿不解人间意，犹向斜阳万里游。"

# 校验一首词
python3 engine/gedou.py --cipai 浣溪沙 --title "秋江送别" \
  --ci "一曲离歌送客舟，西风落叶满江秋，寒烟衰草锁汀洲。别后相思何处寄，楚天无际两悠悠，孤帆影没暮潮流。"

# 重跑六道验收题（会重写 05_创作库 与 06_迭代记录）
python3 engine/run_acceptance.py

# 重建韵书简体索引（换了韵表数据时用）
python3 tools/build_lexicon.py
```

退出码：`0` = 格律合格，`2` = 存在错误（便于接入 CI／批处理）。

## 引擎能力边界

| 能判 | 不判（标注「需人工复核」） |
|---|---|
| 出律（二四六字） | 合掌 |
| 失对、失粘 | 四平头、摞眼 |
| 落韵／出韵、撞韵 | 意象陈腐、套路化 |
| 孤平、三平调、三仄尾 | 情理不通 |
| 重字、重韵 | 工拙高下、余味 |
| 句式字数、词牌谱、词韵同部 | 文学性评分 |

## 依赖

- Python 3.9+
- 仅 `tools/build_lexicon.py` 需要 `opencc-python-reimplemented`（用于繁简转换，一次性）；
  引擎本身**零第三方依赖**，只读本地 JSON。
- 韵表来源：平水韵 106 韵全表（繁），经 OpenCC `t2s` 转写为简体索引。

## 已知局限

1. **多音字**按「可读为平／可读为仄」放宽，不做词义消歧，故个别处可能放过。
2. **对仗**只做词性／结构的粗检（词典覆盖约 400 字），不判工拙，未覆盖字标「未定」。
3. **词牌**仅 3 个；词韵只处理平声十四部（仄韵词牌未接入）。
4. **文学性**不进引擎，只给清单式自查（诗话摘录最后一节）。
