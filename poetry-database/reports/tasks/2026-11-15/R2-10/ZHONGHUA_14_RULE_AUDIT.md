# R2-10/E 《中華新韻》十四韻規則審計

## 1 性質

本項目沒有一條《中華新韻》原書字表。7,216 條全部由**拼音韻母規則**派生，
`evidence_level='DERIVED_PINYIN'`，`semantic_evidence='COMPUTED_FROM_PINYIN'`。
它反映的是「現代普通話按韻母歸類」的結果，**不是任何一本韻書的原文**。

## 2 規則表 14 條 vs 實際出現 13 韻

`ph_modern_rule_r2_09` 定義 14 條規則，但 7,216 條記錄只落在 13 個韻：

| 韻 | 條數 |
|---|---:|
| 一麻 | 366 |
| 二波 | 596 |
| 三皆 | 226 |
| 四開 | 230 |
| 五微 | 147 |
| 六豪 | 647 |
| 七尤 | 237 |
| 八寒 | 1,119 |
| 九文 | 407 |
| 十唐 | 463 |
| 十一庚 | 819 |
| 十二齊 | 1,264 |
| **十三支** | **0** |
| 十四姑 | 695 |

**十三支為 0**：支韻對應 zhi/chi/shi/ri/zi/ci/si 等**整體認讀音節**，
其「韻母」在拼音方案中是 -i（舌尖前/後），不屬於常規韻母表，規則無法匹配。
這是規則設計的漏洞，不是資料缺漏。

## 3 多音字

按拼音派生時，一字多音會產生多條記錄（同一字落在不同韻）。
本輪未做多音字消歧，故 7,216 條中同一字可能出現 2–3 次。
使用時必須按「字＋語境」而非「字」查詢。

## 4 結論

可用於「現代讀音大致屬哪韻」的粗查，**不可**作為詩詞創作押韻的權威依據，
更不可與平水韻／詞林正韻混用。
