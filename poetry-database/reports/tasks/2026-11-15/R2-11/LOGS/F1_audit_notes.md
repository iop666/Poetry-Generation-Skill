## 四、判定口径

- **PASS**：所述与库内文本/字段/词谱可对上，且引句能在原文检出。
- **ISSUE**：与库文本、库字段、对勘表或词谱矛盾；或结论虽可通但归因/字位/句式有实质错误；或引句在原文查无。
- **UNVERIFIABLE**：系年、本事、版本谱系、选本题名、上古韵部等库内无任何字段可核者。**未以常识补足，一律记 UNVERIFIABLE。**

### 附带发现（超出 15 首范围，供批次层面参考）

**D. `text_norm` 被校记污染，影响面 339 条。**
```
SELECT count(*) FROM works WHERE text_raw LIKE '%一作%';        → 339
SELECT work_id,substr(text_norm,1,60) FROM works WHERE text_raw LIKE '%一作%' LIMIT 5;
→ tang300:e76306ad91e2 …王孫歸不歸明年        （多出「明年」）
→ tang300:89b0503bf86e …深坐顰蛾眉顰見淚痕溼…  （「顰」重复）
→ tang300:b73c8ea1e009 …功蓋三分國名成八陣圖名成江流…（「名成」重复）
```
`text_norm` 把括注里的「一作：X」内容当作正文串入，导致这 339 条的 `text_norm` 不是可用的纯文本。C19 的 `char_count=196`（实 176）、C14 的 58（实 56）、C20 的 290（实 285）均由同一原因产生。建议在批次层面把校记拆到独立字段（`variant_note`），重算 `char_count`，否则任何以 `text_norm` 为输入的统计（字数、韵位、字频）在这 339 条上都会偏移。
