# WORKS_SOURCE_LIMITATIONS — 来源追溯的边界

1. **「有来源」≠「有善本」**：全部 375,399 条来自 chinese-poetry 的二手整理，其 `reliability` 自述「未与任何印本对勘，无校勘记录，不可作权威底本」。本轮建立的只是「数字文件级」追溯，不是「版本校勘」。
2. **43.7% 可定位 ≠ 43.7% 已校勘**：`TEXT_OFFSET_LOCATOR` 只说明「这条作品来自该文件的第 N 个元素」，不说明该元素本身正确。30 条逐字 EXACT 只证明**导入未改字**，不证明**源文无误**。
3. **214 个来源无法下标定位**：因导入过滤/合并导致 works 数与 JSON 条数不等，需逐文件比对才能恢复，本轮未做。
4. **无卷页定位**：chinese-poetry 不含卷次页码；要得到 `PAGE_LOCATOR` 必须引入影印本或善本目录，本轮未做。
5. **83 个非 JSON 文件**：格式未确认，可能对应部分来源实际不可解析。
6. **3 个抓取失败文件**：其 `parse_status=PARSED` 是错的，说明历史元数据不可全信。
7. **30 条对校样本偏小**：集中在少数来源（3 个 source），不能代表全部 551 个来源的导入质量。
