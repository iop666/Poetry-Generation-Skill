# WORKS_TEXT_RECONSTRUCTION_RULE_AUDIT — 正文重建规则审计

## 1 被审规则

R2-13 的规则：对无括号「X一作Y」，
- 原句长 ∈ {4,5,6,7} → 保留；
- 删「一作Y」后合律而原长不合律 → 删除 Y；
- 两者皆合或皆不合 → `UNRESOLVED` 并保留原文。

## 2 外部审查的批评与回应

**批评**：以格律裁决原文会循环论证（先按格律改，再用改后文本验证格律）。

**回应**：接受。本轮将该规则**降级为「疑点标记」**：
- 不再用它删除任何字符；
- 53 条中 33 条改判 `UNRESOLVED`，保留原文字面；
- 只有括号结构明确时（`（…一作…）`）才做剥离，因为括号是**排版证据**而非格律推断。

## 3 反例清单（25 条，见 `TEXT_NORMALIZATION_GOLDEN_80.csv`）

| 类型 | 为什么格律会误判 |
|---|---|
| 古体诗 | 句长本就不定，4–7 字规则无意义 |
| 长短句（词） | 句长由词牌决定，非五七言 |
| 拗句 | 字面合律但平仄特殊，按格律会误删 |
| 衬字（元曲） | 衬字不占正格，删了会丢字 |
| 作者自注 | 「一作」在自注里，属作品内容 |
| 无括号异文 | 无法判断哪个是正文 |
| 小序/题下注 | 常含「一作」，但属作品结构 |
| 版本校记 | 编者所加，可剥离但需与正文分开 |

## 4 结论

- 格律规则**只能用于排序候选、提示异常**，不能作为定文字的主要依据。
- 正式的裁定依据优先级：① 影印本/善本 > ② 校勘记 > ③ 多个独立数字版本一致 > ④ 格律提示（仅参考）。
- 本轮无一条达到 ①，29 条达到 ③（与源 JSON 逐字一致）。
