# KNOWN_DATA_DEFECTS — R2-14 缺陷台账

承接 R2-13 的 GD-001~GD-035，本轮新增 GD-036~GD-044。**历史缺陷不因本轮新候选而自动关闭。**

| ID | 缺陷 | 状态 | 本轮证据 |
|---|---|---|---|
| GD-001~035 | 见 R2-13 台账 | 状态不变 | 本轮仅 GD-036 起新增 |
| GD-036 | `record_locator` 全空，来源定位体系未建立 | **PARTIAL 关闭** | 查明**不是无来源**：`source_id` 100% 有、941 条 sources 登记、819 个本地文件全存在；551 个来源可精确定位到数组下标（覆盖 164,217 条 / 43.7%）。仍无卷页定位 |
| GD-037 | 339 条正文候选均无 `SOURCE_CONFIRMED` | 保持 OPEN | 本轮 339 条中仅 **29 条**可定位到源文件下标并逐字对校（29/29 EXACT），310 条来源不可下标定位 |
| GD-038 | 正文恢复判据依赖句长/格律，可能循环论证 | **OPEN（已降级为提示）** | 本轮明确「格律只能提示异常，不能裁决正文」；53 条待审中 33 条标 UNRESOLVED，不再依格律定案 |
| GD-039 | 元曲 2,101 恢复估计分母未明确 | 由专项重算 | 见 `YUANQU_2101_RECOVERY_ESTIMATE_RECALC.md` |
| GD-040 | 73 个作者名称分类合计只有 72 | 由专项对账 | 见 `AUTHOR_73_NAME_COUNT_RECONCILIATION.csv` |
| GD-041 | `author_name` 与 `author_canonical` 权威性未定 | **OPEN** | 1,000 抽样中 364 条两者不一致；`authors` 表由 works 反推，非独立源 |
| GD-042 | 1,678 组跨作者同文未核实 | PARTIAL | 本轮深查 ≥100 组 |
| GD-043 | 1,000 抽样用 rowid 模数，存在系统偏差风险 | **CLOSED（实测无偏）** | 13 个模类中最大总集占比偏差 **0.01%**（songshi 67.36%~67.37%），未发现系统偏差；但仍非等概率随机抽样，不能外推 |
| GD-044 | 词谱图像与 form_id 未建立区域级关系 | **PARTIAL** | 本轮建立 11 个 region（含 x0/y0/x1/y1 与首末谱行），1 条需按标题 y 拆切；**格级映射仍未确认** |
| GD-045 | `sources.parse_status` 不可信 | **OPEN（本轮新发现）** | 3 个抓取失败文件（内容为 "Package size exceeded 50MB"）仍标 `PARSED` |
| GD-046 | `seq` 是全局序号而非数组下标 | **OPEN（本轮新发现）** | CP-TANG-08 max(seq)=7,723 而文件仅 1,003 条；需按 source 内排序才能反推下标 |
