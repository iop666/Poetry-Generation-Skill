# EXAMPLE_LINK JOIN ID 审计（R2-14 / F4）

结论：**R2-10 的 `EX-01 … EX-20` 不是 example_id，而是该轮的轮内序号**。按 `example_id` 直接 join 会产生整批错位；正确做法是用例词正文首 8 字反查 `cipai_form_examples_r2_08`。

## 1. 三轮对象口径

| 轮次 | 文件 | 行数 | ID 形态 | 可否按 ID join |
|---|---|---|---|---|
| R2-10 | `EXAMPLE_100_INDEPENDENT_REVIEW.csv`（`review_type=INDEPENDENT_AGENT`） | 20 | `EX-01…EX-20`（**轮内序号**） | 否 |
| R2-11 | `EXAMPLE_LINK_100_FINAL_AUDIT.csv` | 88 | `link_id=EX-0049` 等（真 example_id） | 是 |
| R2-12 | `EXAMPLE_LINK_100_INDEPENDENT_VERIFICATION.csv` | 100 | `EX-0005` 等（真 example_id） | 是 |
| R2-13 | `EXAMPLE_LINK_UNSEARCHED_100_RESEARCH.csv` | 102 | `EX-0017` 等（真 example_id） | 是 |

R2-10 那 20 条的 `item_id` 形如 `EX-01`（两位，无前导零补位到四位），与 `EX-0001` 起编的 example_id 只是**字符上巧合**；同一文件里另有 310 行 `NOT_REVIEWED`，其 `item_id` 才是 `EX-0001…EX-0310`。因此该文件内混用了两套编号。

## 2. 按 ID 硬 join 的后果（实测）

把 `EX-01…EX-20` 补零成 `EX-0001…EX-0020` 后 join：

- join 得 20 行，其中**真重合仅 2 条**（EX-0011、EX-0015），**假重合 18 条**；
- 三轮 ID 并集表面上是 88+100+20=208 条，"正好"等于 208，但这 208 条里有 18 条是幻影（`EX-0001…EX-0020` 中除 2 条真重合外的 18 条，本不属于 208 集合）；
- 真正被覆盖的对象只有 88+100+2=190 条，**18 条真对象（EX-0038、EX-0044、EX-0076、EX-0088、EX-0096、EX-0115、EX-0122、EX-0157、EX-0186、EX-0220、EX-0234、EX-0242、EX-0255、EX-0271、EX-0274、EX-0294、EX-0301、EX-0307）落空。

> 任务书称「按 ID join 会得 192 条 + 16 条假重合」。按本库实测应为 **190 条 + 18 条假重合**：R2-10 的 20 条中真正落在 `EX-0001…EX-0020` 区间内的只有 2 条（EX-0011、EX-0015），不是 4 条，故"真重合"少 2、"假重合"多 2。此处以可复算的实测值为准，任务书的 192/16 疑为按 4 条重合估算。

## 4. R2-13 的 208 表是否已按正确口径挂接

208 表中带 `R2-10:` 状态的行共 20 条；其中 example_id 属于首 8 字反查真集合的有 20 条，不属于的有 0 条。

即：**R2-13 的 208 表本身是按首 8 字挂接的，未受 ID 混用影响**；ID 混用的风险只存在于"直接按 ID 合并三轮"的做法。本条审计的作用是把这个隐性陷阱写明，并给出可复算的替代路径。

## 5. 复算口径

```sql
-- 例词首 8 字（以 EX-0122 为例）
SELECT example_id, substr(text,1,10) FROM cipai_form_examples_r2_08 WHERE example_id='EX-0122';
-- 反查：首 8 字唯一命中
SELECT example_id, cipai_name, author FROM cipai_form_examples_r2_08
 WHERE replace(substr(text,1,8),'，','') LIKE '水调数声持酒听%';
```

去重口径：三轮对象互不重叠（R2-11 的 88 个 link_id 与 R2-12 的 100 个 example_id 交集为 0，与 R2-10 的 20 条真对象交集亦为 0），20+88+100=208 即唯一对象数；再加 R2-13 新查的 102 条，合计 310，与例词表总行数一致。
