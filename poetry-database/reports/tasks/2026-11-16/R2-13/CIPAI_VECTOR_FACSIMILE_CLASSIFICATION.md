# CIPAI_VECTOR_FACSIMILE_CLASSIFICATION — 词谱图像证据性质

## 1 判定

第二审查者独立报告：11 幅图呈**白底矢量重排**特征（纯黑符号、无纸纹、无墨迹深浅、无扫描噪点、符号等距）。

主 Agent 复核同意：这些 PNG 由 PDF 页面按 600dpi 渲染而来，而该 PDF 本身是**矢量排版**（有完整文字层，`get_text()` 可取到「＋｜－」与括注）。因此图像证据性质为：

| 类型 | 是否适用 | 说明 |
|---|---|---|
| `FACSIMILE_SCAN` | **否** | 无扫描件特征 |
| `DIGITAL_PAGE_IMAGE` | **是** | 由数字版 PDF 渲染 |
| `VECTOR_RECOMPOSED_PAGE` | **是**（更准确） | PDF 为矢量重排页面 |
| `PDF_TEXT_RENDER` | 是 | 文字层与图像同源 |

## 2 后果

1. 「图像与文字层一致」不能证明「书与库一致」——两者同源于同一矢量 PDF。
2. `IMAGE_DOUBLE_REVIEW_MATCH` 只能证明**渲染层面**双人读法一致。
3. 若要做真正的纸本核验，必须另找纸质扫描件（如《唐宋词格律》旧版影印），本轮**未取得**。

## 3 页码与文件的错位

11 条中至少 3 条图内标注页与文件名页号不一致（如文件 `p230`、图内标 215）。这进一步说明「文件名 → 页面」的映射不可靠，须以图内词牌名与标题为锚。

## 4 结论

R2-11 所称「600dpi 原图复核」应更正为「600dpi **数字版页面**渲染核对」。证据等级不得记为 `FACSIMILE_IMAGE_DIRECT`，应记为 `DIGITAL_PAGE_IMAGE`。
