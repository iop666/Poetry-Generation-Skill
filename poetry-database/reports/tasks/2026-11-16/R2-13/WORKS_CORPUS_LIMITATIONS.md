# WORKS_CORPUS_LIMITATIONS — 抽样结论的适用边界

1. **不能外推为「全库 8.1% 有问题」**：1,000 条是分层抽样（按时代/体裁/特征配额），不是等概率随机抽样。各层权重被人为设定，故比例只对「这 1,000 条」成立；若要估计全库问题率，需按各层真实占比加权。
2. **层间不重叠**：为保证唯一 work_id，一条记录只归一层。因此「长篇」「带注释」「复杂多版本」三层只覆盖了尚未被前七层取走的记录，不代表长篇作品的全貌。
3. **重复判定用前 20 字**：会把「同题同体异文」也判为疑似重复（38 条）。全库 3,456 组重复候选同样存在此问题，须人工核版本差异。
4. **`BODY_PARTIAL` 判据宽松**：只检查「是否以标点结尾或长度 ≥20」，会漏掉「以句号结尾但内容被截」的情形。
5. **未核异体字与简繁正确性**：`TRAD_CHARS` 只标记「含繁体字」，未判断该繁简形式是否正确、是否与来源一致。
6. **未核页码混入**：只匹配 3 位以上阿拉伯数字，中文数字页码与版心文字未覆盖（`PAGE_NUMBER` 本轮 0 条，不能据此说「无页码污染」）。
7. **未与原始来源比对**：全部判据基于库内字段互相比对，没有回 `raw/` 或影印件。因此「清白」只意味着「库内自洽」，不等于「文本正确」。
