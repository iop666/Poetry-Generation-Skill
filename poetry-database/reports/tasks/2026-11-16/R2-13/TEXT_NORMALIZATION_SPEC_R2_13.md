# TEXT_NORMALIZATION_SPEC_R2_13 — 作品文本规范化规范（提案，未落地）

> 本规范只作设计与测试依据，**不修改任何现有数据**。

## 1 字段分层（必须分开）

| 字段 | 含义 | 来源 | 可否用于分析 |
|---|---|---|---|
| `text_source_original` | 来源书原文（含校记、小序、编者语） | 原始扫描/转录 | 是（最高） |
| `text_transcribed` | 忠实转录，仅统一编码 | 人工/OCR | 是 |
| `text_body` | 结构化正文（诗/词/曲文） | 本规范重建 | 是 |
| `text_preface` | 题下小序、词牌说明 | 从原文切出 | 是（作背景） |
| `text_annotation` | 作者自注、题注 | 从原文切出 | 是（作注释） |
| `text_variant` | 异文（一作/一本作/一云） | 从原文切出 | 是（作校勘） |
| `text_search_normalized` | 去标点检索串 | 由 `text_body` 生成 | **否**（仅供检索） |

**`text_norm` 降级为历史遗留字段**：可保留，但不得再被当作「作品正文」用于断句、韵脚、字数、例词匹配。

## 2 六条规则

### R1 括号内校记不进正文
`（…一作…）` → `text_variant`；其余括号 → `text_annotation`。正文删除括号全体，**包括注头**（如「(聞 一作：聽)」的「聞」也不留）。

### R2 「一作」在句中时按句长判定
原句长 ∈ {4,5,6,7} → 保留；删「一作Y」后句长 ∈ {4,5,6,7} 而原长不 ∈ → 删 Y；否则保留并标 `UNRESOLVED`。

### R3 不删任何异文
所有被删的校记必须进 `text_variant`。删除即丢失，是本轮之前最大的隐性损失（322 条 `VARIANT_LOST`）。

### R4 编者语与考证文字不入正文
`（同前。）`、`（〖1〗按…）`、`（見…）` 类整块归 `text_annotation`。括号不配平或出现「）（」「（〖N〗按」时，正文截断至首个括号并标 `NEEDS_REVIEW`。

### R5 自注/小序属作品本身
「时年十七」「有序」「并序」「一名××」等，属 `text_preface`，**不删**。这是 R2-12 的 42 条 `POEM_BODY` 的教训。

### R6 检索串由正文派生，不反向污染
`text_search_normalized` 只用于检索；任何分析必须用 `text_body`。

## 3 状态定义

| 状态 | 判据 |
|---|---|
| `SOURCE_CONFIRMED` | 与原始来源逐字核对通过（**本轮 0 条**） |
| `TEXT_STRUCTURE_CONFIRMED` | 结构清晰，无需改动 |
| `SUPPORTED_RECONSTRUCTION` | 有据重建（括号剥离/异文判定） |
| `NEEDS_REVIEW` | 结构错乱或判据冲突 |
| `UNRESOLVED` | 无法判定 |

## 4 固定样本

`TEXT_NORMALIZATION_GOLDEN_50.csv`（实得 55 条），覆盖 8 类结构：括号异文、无括号异文、小序/题注、自注、词牌说明、编者标记、卷页信息、长篇。每条含 `raw_excerpt` / `old_norm_excerpt` / `expected_body_excerpt` / `assertion`，可直接作为回归测试输入（**全部取自真实库记录，不是程序生成**）。

## 5 未解决

- 「一作」在句首且删后仍合格律时（如「一作芸香吏」），句长规则可判；但若原句与删后句长相同，规则失效 → 归 `UNRESOLVED`（本轮 40 条中占多数）。
- 未处理「词牌说明」与「正文」在同一行的情况（如「（一名××）○○○」）。
