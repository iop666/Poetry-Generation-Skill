## 一、结论先行（与 R2-12 的差异）

R2-12 的 GD-032 写「**2,447 条元曲只剩科白、曲文丢失**」。本轮独立复核后，这个判断**不成立**，需改写为两条事实：

| R2-12 原说法 | 本轮核实 |
|---|---|
| 2,447 条只剩科白 | **2,447 是 SQL 括号解析的假象**：`text_raw LIKE '%(%唱)%'` 只认 ASCII 圆括号，漏掉 292 条全角「（）」和 1 条混用「(唱）」。用中英括号通配的正则，同类记录是 **2,740 条** |
| 这 2,740 条曲文丢失 | 其中 **2,739 条曲文就在正文里**（`LYRIC_PRESENT`），只有 **1 条**真正只有宾白 |
| —（未发现） | 真正的曲文损失在**另一个方向**：**1,729 条套数（`title_raw` 含「・」，每支曲牌一段）的曲文前半截被上游刮进了 `title_raw`**，正文只剩后半截；另有 **372 条曲文被刮进 `title`、正文不足 8 字，被导入脚本当「过短」丢弃** |

一句话：**不是「只剩科白」，是「曲文被劈成标题+正文两截」，以及「宾白与唱词混排被误读」。**

## 四、恢复方法与证据

`title_raw` 形如「`曲牌`・`曲文前 N 字`」，`text_raw` 是紧接着的后半截。

以 `yuanqu:442684b0565a` 为例：

```
title_raw : 尾声・春残连理枝，香冷合欢扇，好姻缘翻做了恶姻缘。还不彻相思债，
text_raw  : 叫不应离恨天。\n知他是甚时相见，两眉峰重画翠婵娟。
恢复后正文 : 春残连理枝，香冷合欢扇，好姻缘翻做了恶姻缘。还不彻相思债，叫不应离恨天。
             知他是甚时相见，两眉峰重画翠婵娟。      (21 → 46 字)
```

- 接缝检验：`title` 尾「，」+ 正文首「叫」直接相接，语义连续，无重字（100 条候选中 0 条需要去重）。
- 曲牌还原：`title` 应为「尾声」，原 32 字标题中的后 30 字全部是曲文。
- 长度证据：1,729 条中 **1,425 条 title 长度恰为 32 字**（235 条 33 字），说明上游在固定列宽处硬切。

产出：
- `YUANQU_200_SOURCE_SAMPLE.csv` —— 分层 200 条回源核对（100 可恢复 / 80 源即完整 / 20 不可恢复）
- `YUANQU_100_RECOVERY_CANDIDATES.csv` —— 100 条**逐字可复原**候选，全部 `confidence=HIGH`，
  每条带 `source_locator`（raw JSON 的 `#index=`）与 `source_sha256`
- 候选表只收「曲文确实在本地文件里」的记录；找不到的一律留在 200 抽样表标 `SOURCE_UNAVAILABLE`，**未编造任何字**

## 六、对下游（平仄 / 韵脚分析）的影响

### 6.1 已发生的影响

1. **1,729 条套数的文本被系统性截短 41.7%**，且缺的是**开头**。
   曲的韵脚多落在**句末**，开头缺失会直接导致：
   - 首句、次句的韵脚候选消失 → 韵部统计**少计**；
   - 平仄串开头被打断 → 按「句」切分时首句变成残句，`五/七言` 定长校验全部失效。
2. **`char_count` 系统性偏小**（`char_count` 恒等于 `len(text_norm)`，忠实记录了被截后的文本）。
   任何以 `char_count` 做「体型/长短」分层的分析，这 1,729 条都被错分到「小令/短曲」。
3. **`title_raw` 污染 32 字**：按标题匹配曲牌时，若用 `title_raw` 尾段做 key 会全部失配；
   必须用「`・` 前的部分」才拿到真曲牌。
4. **1 条纯宾白混在「曲」里**（`yuanqu:dba46748341c`），若做曲律统计会引入一条非曲文本。
5. 41 条残篇若参与韵脚统计，会给出**伪韵脚**（句子被切断处的字被当成句尾）。

### 6.2 未受影响的判断

- **不能推出「元曲整体不可用」**：2,739 条杂剧/套数记录的曲文完整（抽样 80 条回源，全部逐字相同）。
- 「`(…唱)` 结尾 = 缺文」这个推断是错的：1,144 条以唱句提示结尾的记录中，
  **1,132 条的下一条记录正文 ≥15 字**（即唱词在下一段），只有 12 条下一条也短。
  这类结尾只是「段末提示」，不是损失。

### 6.3 建议（不在本轮执行，仅记录）

- 恢复 1,729 条：`title_raw` → 曲牌；`text_raw` → `title` 载文 + 原正文；重算 `char_count`/`line_count`。
- 重导 372 条：解除 `len<8` 硬过滤，改为「`title` 含句读则视为正文候选」。
- 在 `works` 增列 `text_origin`（`BODY` / `TITLE_MERGED` / `TRUNCATED_SOURCE`），让下游能过滤。
- 41 条残篇 + 1 条宾白打 `NOT_FOR_PROSODY` 标记。
