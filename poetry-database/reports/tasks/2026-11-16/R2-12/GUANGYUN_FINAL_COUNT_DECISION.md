# GUANGYUN_FINAL_COUNT_DECISION — 广韵小韵数的最终口径决定

## 决定

1. **不使用单一「广韵小韵数」**。今后凡引用该数字，必须同时给出底本、判据与口径名。
2. 本项目对外表述统一为：
   > 《广韵》小韵数，依《欽定四庫全書》本《原本廣韻》维基文库转录、以「行内圆圈标记＋代表字＋反切起首」为判据，得 **3,730**（候选区间 **3,565–3,758**）。该数字为转录口径候选数，未与原书影印本全量校勘。
3. **3,706 作废**（推导不可复现）。**2,907 作废**（判据把又音与断页首排除过多）。
4. 3,702 / 3,872 / 3,874 **仅作外部参照**，不得替换本项目底数。

## 三条口径的适用场景

| 口径 | 适用 | 不适用 |
|---|---|---|
| 3,730 核心 | 韵书结构研究、与外部统计比较 | 声称「广韵共有多少小韵」定论 |
| 3,565 有切语 | 中古音声韵推导（要求切语可用） | 结构统计（会漏掉断页首） |
| 3,482 规范二字切 | 自动化反切切分、拼音化 | 同上 |

## 已知不可靠项（影响 3,730 的精度）

1. GD-029 转录列序交错：690 条 POSSIBLE 中 323 条已确认同型，3,730 内部的同型错误比例未知。
2. 28 条候选未做图像确认（可能使上限升至 3,758）。
3. 添、狠两韵韵目行在转录中缺失，靠「代表字＝韵目名」定韵，属推断（303 条 SUPPORTED_POSITION 中部分由此产生）。

## 为什么不能给「定论」

外部审查要求「按明确底本及结构标记重新统计，解释与其他统计的差异」。本轮做到了前两句，**第三句只做到统计级解释**：28 条差额无法逐条对应，因为文脉项目未公开条目索引且禁止自动访问。在这一步完成前，任何「定论」都是超证据陈述。

## 下一步（R2-13）需要的最小工作量

1. 用浏览器人工下载 SBL015 全 307 页 → 建立叶码表 → 逐叶读小韵首序列 → 与 3,730 逐条比对。
2. 若得 3,70x 量级，则 3,730 需下调，差额即 GD-029 交错制造的伪首。
3. 该工作约需 40–60 叶精读（每叶 20–35 小韵），可覆盖全部 206 韵。
