## 2 已观察到的差异（卷一「一東」）

| 小韵 | 转录（T-四库） | 影印（F-宋刻） | 判定 |
|---|---|---|---|
| 東 | 徳紅切，注末「十七」 | 徳紅切，注末「十七」 | 一致 |
| 同 | 徒紅切 | 徒紅切 | 一致 |
| 中 | 陟弓切 | 陟弓切 | 一致 |
| 蟲 | 直弓切 | 直弓切 | 一致 |
| 終 | 職戎切 | 職戎切 | 一致 |
| 忡 | 敕中切 | 敕中切 | 一致 |
| 嵩 | 息弓切 | 息弓切 | 一致 |
| 戎 | 如融切 | 如融切 | 一致 |
| 崇 | 鋤**功**切 | 鋤**弓**切（字迹略糊） | **DIFFERENCE_PENDING** |

「崇」的切下字在影印本似作「弓」，转录作「功」。二者声母相同（见母），韵母「弓」属東韵三等、「功」属東韵一等，**会影响等呼判断**，须以更高分辨率复核后定。本轮不作裁定。

## 3 版本差异的处理规则

1. 同一小韵在两版本中反切不同 → 记 `SOURCE_VARIANT`，两值并存，不覆盖。
2. 仅一方有该小韵 → 记 `EDITION_ONLY`，并注明是否可能为缺页。
3. 注文字数不同 → 记 `COUNT_VARIANT`，不据以否定任一方。
4. 只有**影印本可辨且转录明确有误**时才可判 `TRANSCRIPTION_ERROR`，且须保留原值。

## 4 影响面

由于本轮只对校了 9 条，**不能推断整本转录的错误率**。已知 1/9 存在切下字差异（11%），但样本极小且集中在同一叶，不具统计意义。下轮须在建立叶码映射后扩大样本。
