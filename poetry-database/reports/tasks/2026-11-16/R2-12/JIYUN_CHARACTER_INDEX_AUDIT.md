# JIYUN_CHARACTER_INDEX_AUDIT — 集韵字级索引

## 1 建了什么

`jiyun_char_index_r2_12`（42,352 行 / 23,938 个不同字）与 `jiyun_entry_r2_12`（33,664 个「字组」）。

每条字级记录含：`character, rhyme_group, xiaoyun_id, xiaoyun_seq, is_xiaoyun_head, char_group, fanqie, source_page, source_offset, align, evidence_level, verification_status`。

## 2 建法（v1→v3 的三次迭代，如实记录）

| 版本 | 方法 | 结果 | 放弃原因 |
|---|---|---|---|
| v1 | 直接按「○」全文切分 | 4,327 段 / 34,779 组 | ○ 有 4,442 个，含注文中的 ○，段数虚高 |
| v2 | 全文顺序锚点（head+〈） | 仅 665/4,169 锚定 | 注文中同名字造成游标漂移 |
| **v3** | **页内 ○ 分段 + 与该页小韵表贪心对齐** | **4,122/4,169 有落点** | 采用 |

对齐质量：`HEAD_MATCH` 3,569、`OUT_OF_ORDER` 364、`POSITION_ONLY` 227、`NO_SEGMENT` 9。

## 3 关键设计

1. **小韵首与成员字分开**：`is_xiaoyun_head=1` 仅 4,122 条（每组第一条）。成员字 29,542 组，全部 `is_xiaoyun_head=0`、无独立反切。
2. **异体组保留**：一个「字组」如 `䎩載𤰭䅔𦿸` 共用一条注，组内每字各成一行，`char_group` 保留原组，便于回溯。
3. **一字多处保留多处**：同一字在不同小韵出现则多行，不去重（如「東」在東韵与它韵各有一行）。
4. **不丢弃无切语字**：成员字无反切，仍入索引，韵目由所属小韵给出。
5. **无法确定位置的保留**：9 条 `NO_SEGMENT` 未强行安放。

## 4 能回答什么、不能回答什么

| 问题 | 能否回答 |
|---|---|
| 「某字在集韵属哪一卷哪一韵」 | **能**（韵级可靠，小韵级 98.9% 有落点） |
| 「某字在集韵的反切」 | 仅当该字是小韵首（4,122 条） |
| 「某字在集韵的现代音值」 | **不能**（无反切则无声韵地位） |
| 「某字是否异体」 | 部分能（`char_group` 显示同组） |
| 「该字在影印本哪一叶」 | **不能**（未做影印对校） |

## 5 与 R2-11「30,862 条」的关系

R2-11 的 30,862 与 14,740 两个数字**无法用当前数据复现**（见 `JIYUN_COUNTING_RECONCILIATION.md`）。本轮改用「字组 33,664 / 单字 42,352 / 不同字 23,938」三口径，并明确粒度。**不宣称 30,862 已完成**。
