## 3 本次实际工作

### 3.1 五步走

**第一步　建阅读通道，先修一个会吞字的 bug**

`r2_05_dump.py` 的分页输出能跑通，但第一版清洗正则写成 `\$?\\underset\{\\cdot\}\{([^}]*)\}\$?`，漏了 `$` 与 `\underset` 之间的空格。原书 OCR 实际输出是 `$ \underset{\cdot}{书} $`，于是 3,424 处被「字下加点」标记包裹的字**全部被吞**——起初读 A 第二章第二节的例诗，韵脚整批消失（「猿鸟犹疑畏简」缺「书」）。修正后 `p15–26` 汉字数 4,859，与清洗前一致，确认不再吞字，然后重读受影响章节。这不是小修：若不查，后面所有引文都会缺字。

**第二步　按原书目录重建阅读单元，不沿用旧索引**

以 PDF p8–p10 的总目录为准，确认合订本实为**四部分**（与 R2-04 一致，本轮复核无误），并确认「印刷页＝PDF 物理页 − 8」在 A、B 两部分都成立。逐单元取「起页—止页—节数」，17 个章级单元、共 47 个节级单元。

**第三步　逐个单元通读**

按 PDF 物理页逐页输出，一页不跳。A 部分 9 个单元（引言、四章、结语、三附录，p15–182）、B 部分 8 个单元（卷上四章＋卷下四章，p187–346），合计 **88,194 汉字全部过目**（A 57,086／B 31,108）。

**第四步　遇到不可读的数据就回原图**

平仄格式谱是诗律的骨架，但 OCR 每逢「字外加圈」就吞一字（五言 5 字变 4 字）。本轮渲染原图核验 6 页（A p35、p36、p37、p38、p59、p120），把五律、七律、五绝的四种格式逐行补全，并确认「质物锡职缉」是**原书排印错误**而不是 OCR 错误。这一步决定了本轮能不能说「诗律读懂了」——只读 OCR 文本是读不出格式的。

**第五步　边读边落笔记，读完整批入库**

每个单元读完立即写 `raw/r2_05_notes/*.md`，含定义、逐字引文（带双页码）、适用范围、例外、与邻章关系、待追踪问题。全部读完后用 `r2_05_ingest.py` 一次性入 `reading_records_r2_05`、`poetry_rules_r2_05`、`two_book_diff_r2_05`，并处理 `theory_claims`。

### 3.2 三个重要决策

**决策一：`A:附录三`、`B:卷下第一章` 判 READ，但「谱表可引用性」判假**

这两单元的文字（调名、字数、注记、例词、句式说明）可读且已读完；谱行不可用。若因谱行不可用就判整章 EXTRACTED，等于说「因为表格糊了所以正文也没读」，不符合事实；若判 READ 而不说明，又会让后续误以为谱表可用。故：**状态 READ ＋ `ocr_exception` 明确写「谱行不可用，不作数据源」**，并在覆盖报告里把「章节已读」与「谱表可用」分开陈述。

## 6 技术实现

### 6.1 清洗管线（`r2_05_dump.clean`）

```
$ \underset{\cdot}{X} $   → X      # 字下加点（入声/韵脚标记），保留字
$ \underset{\triangle}{X} $ → X    # 字下加三角，2 处
$ ^{①} / $^{2}$           → 空     # 脚注号
\text{}/\mathrm{}         → 内容
$ # `                     → 空
[ \t　]+ → 空；连续空行压缩
```

**关键**：正则必须允许 `$` 与 `\underset` 之间有空格，否则静默吞字（本轮已踩过）。

### 6.2 覆盖计算

`coverage = 已读汉字 / 该单元清洗后汉字`；`chars_total` 由 `pages.jsonl` 按 `pdf_from..pdf_to` 累加，与 `reading_units` 的范围严格一致。`gate_pass` 只有在 `status=READ 且 coverage≥1.0 且 sections_done==sections_total` 时为 1。

### 6.3 状态机

`NOT_STARTED → PARSED → READING → READ → EXTRACTED → REVIEWED` 中，本轮实际只产出两种终态：`READ`（八条门禁全过）与 `EXTRACTED`（有笔记、无全文覆盖证据）。**不允许 `EXTRACTED` 自动升 `READ`**，门禁由 `gate_pass` 字段机器判定。

### 6.4 边界

- 不做全文入库（`book_pages_paddle` 已存原始文本，不重复存）。
- 不做跨书术语归一（王力「仄起式」与龙榆生「顺黏格／偏格／正格」并存，见 §8 问题 3）。
- 不入 Phase 3（知识体系）。

## 12 自我审计（至少五个真实问题）

1. **「100% 覆盖」是页级指标，不是理解级指标。** 我把 88,182 字全部过目，但没有任何机制能证明我读懂了王力的论证结构。报告里所有「核心内容」都是我二次概括，可能与原意有偏差——这正是需要外部审核的地方。
2. **38 条规则的引文比对只做到「文本中存在」，没做到「语境一致」。** 例如 R05-009 引的 p47 段落，我截取的是「先说『一三五不论』这句话是不全面的」及其四条理由，但未逐条回抄四条理由的完整句子，读者无法仅凭该条判断我是否漏了第五条例外。
3. **两书冲突的「谁对」我没有裁决，也不该裁决。** 例如「出韵 vs 通韵」，我并列了，但没有考证两书成书先后（B 的初版年未查），所以无法判断这是「作者前后期观点变化」还是「两本面向不同读者的表述差异」。这个空白会影响 R2-06 的取舍。
4. **词学十讲只补了 3 讲，有选择性偏差。** 我挑的是「无任何记录」的 2、5、8 讲，恰好是韵位、四声阴阳这些与格律最相关的；但第 7 讲（论结构，11,129 字，最长）与第 9 讲（论比兴）仍只有旧摘要。用 3 讲的通读去支撑「十讲已复核」的结论，力度不够——报告里已按 3/10 如实标注，但不能排除审核认为这仍属「未完成」。
5. **`reading_units` 的 47 个节级单元，我按章级统一改成 READ，未逐节单独判门禁。** 章级通读成立时，节级必然被覆盖（节是章的子区间），所以这个批量更新在逻辑上成立；但它掩盖了「某节只有 2 页、实际内容全在下一页」这类边界情况。若要严格，应当逐节计算 coverage，本轮没做。
6. **`cipai_index_gap` 的「实际出现次数」是字符串计数，含误命中。** 例如「例 五（小令别格）」中的「别格」是例词标注而非独立词格；「附注：格二、格三……」是引用而非新格。所以 143/27/21/23/8/7 是**上界**，真实词格数需人工判读。我在报告里写的是「实测出现次数」，不是「词格数」，但这层区分容易被读者忽略。
