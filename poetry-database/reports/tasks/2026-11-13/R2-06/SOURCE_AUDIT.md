## 二、本轮的来源级判断

### 1. 页码映射不是推断，是校验出来的

三处独立证据（C 目录 344/347/350 → PDF 352/355/358；A 目录引言 7 → PDF 15；B 目录 179 → PDF 187）共同指向**全书统一偏移 8**。
`r2_06_index.py` 把这三处写成硬校验：任一处不符即 `SystemExit`，不允许把未经验证的映射写进库。

这不只是技术细节——R2-05 的「A 部分 PDF 15–182 vs 印刷 1–174」之所以对不上，就是缺这一步。

### 2. 索引改变了事实认定

R2-05 用字符串检索判定「《宿五松山下荀媪家》全书 0 命中」，据此认为引文是执行者转述。
本轮改用**先查索引、再全文验证**：索引条目「《宿五松山下荀媪家》34,37,47,231,402」直接指向四处正文。
结论翻转：诗在书中，「我宿五松下」也在书中，只有「只算拗句」四字是混入的注家语。

**方法教训**：字符串检索只能证明"这一串字不存在"，不能证明"这件事不存在"。凡要下否定性结论，必须换一条检索路径交叉。

### 3. 版本差异必须原样保留，不能就地统一

| 现象 | 处置 |
|---|---|
| 原书把「阕」排作「阙」（C 讲九、讲十） | 引文照录「阙」，不改成「阕」；仅在与现代写法对照时注明 |
| A p120 词韵入声部作「质物锡职缉」，B p324 作「质陌」 | 记为**原书版本/排印差异候选**，不互相覆盖（R2-05 已记录，本轮沿用） |
| 《词学十讲》脚注 15 列《摊破浣溪沙》异文（绿波/碧波、韶光/容光、鸡塞远/清漏永、多少泪珠何限恨/簌簌泪珠多少恨、真珠/珠帘、三峡/春色） | 全文保留，作为可用的版本校勘材料 |
| 合订本四部分成书先后 | 只根据 C 后记（1964 年改动、后又修订）记录事实，不推断"A 与 B 谁更新" |

### 4. 附录的时代话语必须标记

D 附录开篇近 400 字是 1970 年代政治表态（「我们热烈欢呼毛主席给陈毅同志谈诗的一封信的发表」）。
处理方式：**原文保留**（它是版本年代的证据），但在笔记与理论条目中明确标注"属时代话语，不作诗律内容"，且未从中提取任何规则。

## 四、明确不做的事

1. 不用龙榆生纪念网站目录替代本地原书；仅用其"一百五十余调"作为口径交叉。
2. 不把 OCR 规则、推测补字写进正式格律数据。
3. 不改 `gedou.py`，不动 `cipai_specs`、`works`、`book_pages`。
4. 不把「POTENTIAL_THEORETICAL_CONFLICT」升格为确定结论。
5. 不宣称已读《汉语音韵学》《同源字典》《古代汉语常识》《唐宋词格律》全本。
