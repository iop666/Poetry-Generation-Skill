# 08 版权与合法性报告

**一句话**：128 个采集来源全部为**公有领域古籍**或**明确标注开放许可**的整理数据；
13 种现代版权专著**只登记书目，未下载一字**。本轮未绕过任何付费墙、登录或反爬限制。

## 二、逐类说明

### 2.1 chinese-poetry（103 个文件）

- 仓库：[github.com/chinese-poetry/chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)
- 许可：MIT（Copyright © 2016 JackeyGao）
- 原文：唐宋诗词本身已入公有领域
- **MIT 允许复制、修改、分发，需保留版权声明** —— 本库在 `sources/manifest.json` 与 `sources` 表中逐条记录了许可。
- 该仓库自述「数据来源于互联网」，**整理过程无记录**。因此本项目在可靠性字段统一标注：
  > 「二手整理：来源网站已不可追溯，未与任何印本对勘，无校勘记录。仅可作语料，不可作权威底本。」

### 2.2 维基文库（25 个文件）

- 站点：zh.wikisource.org
- 许可：CC BY-SA 4.0（转录文本）；所收古籍原文为公有领域
- 本项目使用方式：下载 wikitext 原文，去标记生成纯文本，**未修改内容**。
- **CC BY-SA 的传染性**：本项目分发的 `normalized/books/*.txt` 属「改编」，理论上应以 CC BY-SA 4.0 分发，并注明来源。
  本库已在每个纯文本文件头部写入来源 URL、维护者、许可与可靠性说明，满足署名要求。
- 若后续要商用，需重新评估 CC BY-SA 的适用范围。

### 2.3 现代版权专著（13 种，未采集）

包括王力《诗词格律》《汉语诗律学》、龙榆生《唐宋词格律》、《钦定词谱》影印本、
《广韵》《集韵》校注本、《词林正韵》影印本、《中原音韵》、《原诗》、《唐宋诗举要》等。

**处理方式**：
- 只记录 `book_id / 书名 / 作者 / 出版社 / 版本 / 许可状态`；
- **不下载、不摘录、不扫描**；
- 在报告 01 中逐条注明「未取得」及合法取得渠道。

需要注意的区分：
- 《钦定词谱》《词律》《广韵》《集韵》《词林正韵》《中原音韵》《原诗》的**原书**均为公有领域；
  **但本项目所缺的是现代影印本／校注本**，后者有版权。
- 本项目**没有**使用任何现代校注本的正文。

## 三、本轮明确没有做的事

| 禁止项 | 是否遵守 |
|---|---|
| 绕过付费墙 | 遵守。未访问任何付费数据库 |
| 绕过登录或访问限制 | 遵守。未尝试登录、未伪造 cookie |
| 下载明确禁止抓取的资料 | 遵守。仅访问 GitHub 公开仓库与维基文库公开页面 |
| 擅自复制受版权保护的现代图书全文 | 遵守。13 种专著一字未取 |
| 将未知来源的网络文本标记为权威版本 | 遵守。所有二手数据均标「未对勘、不可作权威底本」 |

补充两点自我约束：

1. **未使用「镜像站」或「网盘分享」等来源**：只用了 GitHub 官方仓库与其 jsdelivr CDN、维基文库官方 API。
2. **未规避限速**：采集间隔 0.5 秒，单源最多 4 次重试，失败即记录，不换 IP、不伪造 UA 池。
   UA 中如实写明用途（`PoetryDatabase/1.0 (academic corpus build)`）。

## 四、上一轮遗留数据的版权状态

`诗歌知识库/04_韵书/平水韵_全表_繁体.json` 是上一轮继承下来的，**文件内无编者、版本、网址、许可**。
- 平水韵本身为公有领域韵书；
- 但这份**电子整理本**的出处与许可不明。

**本项目未修改该文件，也未把它当作可信底本**（已在上一轮报告 08 中标注「VERIFIED 未达到」）。
若后续要正式发布，**必须替换为出处明确的版本**，否则存在许可瑕疵。

## 五、合规风险清单

| 风险 | 等级 | 说明 | 处置建议 |
|---|---|---|---|
| chinese-poetry 整理数据实际来源不明 | 中 | MIT 许可覆盖的是整理者的劳动，但上游文本来源不明 | 正式发布前做一次来源追溯；或换用有明确底本的版本 |
| 维基文库 CC BY-SA 的传染性 | 中 | 若整体分发，可能要求整库以 CC BY-SA 发布 | 明确标注各部分许可，或只分发脚本+原始 URL |
| 平水韵电子本许可不明 | 中高 | 无出处即无授权依据 | 替换为可核验版本 |
| 未来引入现代校注本 | 待定 | 一旦引入即受版权约束 | 需用户提供合法版本或授权 |

## 六、结论

本轮采集行为**合法**：只取公有领域原文与明确开放许可的整理数据，未触碰版权内容，未规避技术限制。

但**「合法」不等于「可自由再分发」**：
`normalized/books/*.txt` 含维基文库转录（CC BY-SA），chinese-poetry 部分需保留 MIT 声明，
平水韵电子本许可不明。**若要对外发布整个数据库，须先处理这三项。**
