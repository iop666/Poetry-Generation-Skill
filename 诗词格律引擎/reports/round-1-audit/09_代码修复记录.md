## 二、C-03 判定核心重写（影响面最大）

### 2.1 改动内容

`check_poem()` 与 `check_ci()` 的返回结构、判定流程、输出渲染全部重写。

**旧流程**：选谱（取失律最少者）→ `fits()` 判平仄 → 汇总错误 → 计数。

**新流程**：

```
1. split_lines        按标点切句（字符范围扩到 CJK 扩展 A/B）
2. 体式识别           句数 × 句长 → (7,8)/(7,4)/(5,8)/(5,4)
3. 句式判定           首句第 2 字定起式；首句是否入韵按「与第 2 句韵脚是否同部」判定
4. 取谱               按句式唯一取谱；若第 2 字读音未定则并列候选并披露
5. 逐字判定           六态：PASS / FLEXIBLE / FLEXIBLE_READING / FAIL / UNKNOWN / NOT_CHECKED
6. 特拗覆盖           合法变格改判 FLEXIBLE
7. 押韵               韵脚平仄 + 同部；白脚仄收
8. 粘对               据第 2 字实际平仄
9. 孤平/三平/三仄     按已定读音；读音不足则记待确认，不判违律
10. 重字、未收录
11. 体制判定          偶句韵脚全仄 → 不适用（古体/仄韵体），逐字表置 NOT_CHECKED
12. 判定码            违律 / 待确认 / 合格 / 不适用
```

### 2.2 关键决策点（需审核者复核）

| 决策 | 旧做法 | 新做法 | 理由 |
|---|---|---|---|
| 选谱 | 对四种句式各算失律数，取最少者 | 按首句第 2 字与入韵确定唯一式，不试谱 | 「取最少」等于让谱迁就文本，可能掩盖真实出律 |
| 首句入韵 | 看首句末字声调（平即入韵） | 看首句末字与第 2 句韵脚是否同部 | 「收」等平仄两收字作首句末字时，声调法给不出答案 |
| 不论位 | 不判、直接记「合」 | 记 FLEXIBLE，并注明与正格是否相同 | 未检查不等于通过 |
| 组合规则 | 只写错误文字 | 错误列表 + 立即显现的待确认 | 三平调/孤平涉及多字，单字状态无法表达 |
| 古体 | 无识别 | 偶句韵脚全仄即判不适用 | 近体必押平声韵；否则名篇被系统性误杀 |

### 2.3 一处主动放弃的「智能」

v1 会为每种句式打分然后挑最好的。这看起来更"聪明"，但它有一个无法接受的副作用：
**当一首诗真的写错了，换一个谱可能让错误变少，于是错误被藏起来。**

v2 改为按首句判定唯一样式，错了就错在那一式上。若首句第 2 字本身读音未定，
则并列输出各候选式的违律数，并注明「不代表唯一正解」。

## 三、C-04 孤平规则修正

### 3.1 v1 的错误

```python
# v1 第 318 行，对每个韵句都执行
ping = [c for c in ln[:-1] if "平" in LEX.tones(c)]
if len(ping) == 1:
    errors.append(... "犯「孤平」")
```

孤平的定义要求该句正格是「两平相连」型（五言 `平平仄仄平`、七言 `仄仄平平仄仄平`）。
v1 对**所有**韵句执行，于是五言丁型 `仄仄仄平平` 也被检查 —— 该型除韵脚外本来就只有一个平声，
**必然被判孤平**。

### 3.2 后果

杜甫《春望》第 4 句「恨别鸟惊心」＝ 仄仄仄平平（丁型），被判「孤平」，全诗因此「不合格」。
这是把一首标准五律判成不合格。

### 3.3 修正

```python
pair = (pat[1], pat[2]) if char_len == 5 else (pat[2], pat[3])
if pair == ("平", "平"):     # 只有两平相连型才检查孤平
    ...
```

并按已定读音计数；若有字读音未定，记待确认而非违律。
回归用例：`tests/01_golden_poems.json` G05（春望），期望违律 0。

## 四、C-05 特拗识别

新增 `detect_teao()`：

| 正格 | 特拗形式 | 关键位 |
|---|---|---|
| 五言 `平平平仄仄` | `平平仄平仄` | 第 3 字改仄、第 4 字改平 |
| 七言 `仄仄平平平仄仄` | `仄仄平平仄平仄` | 第 5 字改仄、第 6 字改平 |

返回值三态：`True` 确认（两位读音已定且为仄、平）／`None` 疑似（读音未定）／`False` 不是。
确认时两位记 FLEXIBLE 并在说明中标注「特拗（鲤鱼翻波）」。

回归用例：`tests/05_rhyme_boundary.json` R02（苏轼《饮湖上初晴后雨》）。

## 六、接口变化与兼容性

### 6.1 返回结构

| 字段 | v1 | v2 | 兼容性 |
|---|---|---|---|
| `结论` | `合格` / `不合格（N 处）` | `合格` / `未见明确违律（N 处…）` / `不合近体格律（N 处）` / `不适用近体格律（…）` | **不兼容**：字符串比较会失效 |
| `判定` | 无 | `合格` / `待确认` / `违律` / `不适用` | 新增，建议作为程序判据 |
| `待确认` | 无 | 字符串列表 | 新增 |
| `计数` | 无 | 六态计数 | 新增 |
| `平仄表[].格[]` | `{字,平仄,谱,合}` | `{第,字,正格,实际,韵书,状态,说明}` | **不兼容** |
| `对仗[].结构相似度` | 字符串 `"100%（6/6 字可比对）"` | 改为 `词性位置一致率`（整数或 null）+ `可比对字数` + `一致字数` | **不兼容** |
| `平仄表[].示谱` | 无 | 新增（不论位写「中」） | 新增 |
| `句式依据` | 无 | 新增 | 新增 |

### 6.2 退出码

| 场景 | v1 | v2 |
|---|---|---|
| `结论 == "合格"` | 0 | — |
| `判定 in {合格, 待确认, 不适用}` | — | 0 |
| 其余 | 2 | 2 |

**注意**：「待确认」与「不适用」都返回 0。理由是它们的语义是「未发现违律」，
不是「已证明合格」。接入 CI 时若要求严格，应改判 `判定 == "合格"`。

## 七、修复过程中的真实故障记录

这些是执行中实际发生并修掉的错误，不是事后补写的「已优化」。

| 序号 | 故障 | 原因 | 处理 |
|---|---|---|---|
| 1 | `KeyError: '平仄表'` | `_build()` 返回键为 `表`，`render()` 读 `平仄表` | 在 `check_poem()` 出口统一改名 |
| 2 | `KeyError: '表'` | 改名后古体分支仍读旧键 | 改为读 `平仄表` |
| 3 | `NameError: free variable 'c'` | Python 3.13 生成器内变量作用域变化 | 改用显式循环 |
| 4 | 39 个韵目未被十九部表覆盖 | 源表韵目为繁体且有异名（琰/俭、箇/个、筿/筱） | 加 `YUN_ALIAS` 归一，归零 |
| 5 | 不变量 I3 在古体样本报违规 | 体制判定后整表置 NOT_CHECKED，但示谱仍含「中」 | 检查器跳过 NOT_CHECKED |
| 6 | 不变量 I5 在静夜思报违规 | 押韵/粘对错误不产生逐字 FAIL，条数天然不等 | 改为一致性检查（有 FAIL 必有记录） |
| 7 | 三平调注入样本未触发 | 「三」为平仄两收，改判为待确认 | 判定逻辑改为「无确定仄声即可疑」，同时修正样本用字 |
| 8 | 白脚注入样本未触发 | 「迟」亦两读 | 换单读字「寒」 |
| 9 | 句式判定对自产诗返回「待定」 | 首句末字「收」两读 | 改用韵部判断入韵 |

第 5、6 两项值得注意：**它们不是代码 bug，是检查器口径过严**。
修正时改的是检查器而不是产物 —— 这一点必须交代清楚，否则会被视为「改测试迁就代码」。
区分标准：I5 的原始写法假设「违律数 = 逐字 FAIL 数」，这个假设本身错了（押韵、粘对错误不落在单字上），
所以改假设；而不是把 FAIL 改小以通过。
