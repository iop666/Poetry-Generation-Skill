# 05 逐字校验输出审计

**对应审核**：A04
**结论**：**成立。** 审核点名的现象（第三字「小」为仄却打 ✓，而展示的模板写「平」）确认属实，
根因不是显示格式问题，而是**未检查的位置被当成了通过**。本轮建立六态判定 + 六条结构不变量，
把「模板／字符／读音／结论」四者对不上变成机器可检的违规。

## 一、审核指出的原文

> 例如报告中 T4 的第一句：
> ```
> 格律模板：仄仄平平仄仄平
> 实际字符：●●●○●●○
> 输出：    ✓✓✓✓✓✓✓
> ```
> 第三个字符「小」是仄声，但展示模板第三位是平声。……真正的问题是：输出没有区分固定位置、可变位置、未检查位置和真正通过的位置。

第 1 句：模板第 3 位是「平」，字符第 3 位「小」是「●（仄）」，判定是「✓」。三个字段互相矛盾。

## 三、根因（源码级）

v1 `check_poem()` 第 216 行：

```python
mandatory = [1, 3, 5, char_len - 1] if char_len == 7 else [1, 3, char_len - 1]
```

只把七言的 2/4/6/7 字、五言的 2/4/5 字列为必查位。第 242–246 行：

```python
if j in mandatory:
    ok = fits(ch, pat[j])
    cells.append({..., "谱": pat[j], "合": ok})
else:
    cells.append({..., "谱": "中", "合": True})   # ← 未检查，一律记为「合」
```

三个后果：

1. **未检查被记成通过**：`"合": True` 在所有位置都成立，渲染时统一画 ✓，无法与真正通过区分。
2. **展示的谱不是判定用的谱**：`row["谱"]` 打印的是完整正格 `pat`，而判定实际用的是 `"中"`。
   两个谱同时存在，读者只能看到其中一个。
3. **组合类错误不落到字上**：三平调只写进错误列表，逐字行不会标出「生」「秋」二字的问题，
   于是同一行既有「全平」的错误描述，又有三个 ✓。

## 四、v2 的六态判定

| 状态 | 符号 | 含义 | 何时出现 |
|---|---|---|---|
| `PASS` | ✓ | 固定位置，读音唯一且与正格相符 | 该字在韵书中只有一个声调，且等于正格 |
| `FLEXIBLE` | ~ | 可平可仄位置 | 七言 1/3/5 字、五言 1/3 字；词谱的「中」位；特拗句的两个关键位 |
| `FLEXIBLE_READING` | ≈ | 两读字按白名单放宽 | 见 `04_多音字机制审计.md`，**不计为通过** |
| `FAIL` | ✗ | 固定位置，平仄相反 | 读音唯一且与正格相反 |
| `UNKNOWN` | ? | 读音或韵部无法确定 | 韵书未收录、平仄两收且无定音依据 |
| `NOT_CHECKED` | － | 当前规则未执行检查 | 判为古体／仄韵体后作废整表；词牌句式不符 |

### 4.1 模板与结论的对应

每个位置同时输出两个字段：

- `正格`：定格全字平仄（如 `仄仄平平仄仄平`）
- `示谱`：把不论位改写为「中」后的谱（如 `中仄中平中仄平`）

渲染时打印的是**示谱**，逐字判定按示谱计算。第 3 位是「中」，判定必然是 `~`，**结构上不可能出现 ✓**。

同一首病例（T4）在 v2 下的输出：

```
 1  中仄中平中仄平  独坐小窗夜气清  ●●●○●●○  ~✓~✓~✓✓
 2  中平中仄中平平  一灯明灭照孤城  ●○○●●○○  ~✓~✓~✓✓
 3  中平中仄中平仄  旧约难忘空叹息  ●●◐◐◐◐●  ~✗~≈~≈✓
 4  中仄中平中仄平  露冷空庭生秋风  ●●◐◐○○○  ~✓~?~✗✓
```

第 1 句第 3 字现在是 `~`（可平可仄），与示谱的「中」一致。
第 4 句第 5 字「生」为 `~`、第 6 字「风」为 `✗` —— 但「三平调」是**组合性错误**，
单字状态无法表达「三字合起来全平」。v2 的处理是在行外单列：

```
- 第4句句末「生秋风」三字全平，犯「三平调」
```

即：**组合规则用句级错误列出全部涉及字符，单字状态只承担该字自身的对错。**
这一分工必须在报告里讲清楚，否则会被质疑「为什么三个字没一个标出来」。

### 4.2 未检查必须可见

v1 对判定不了的情况有两种隐瞒：`"合": True`（未检查冒充通过）、以及古体被强行套谱。
v2 增加了两种显式表达：

```
? 待人工确认（未计为通过，也未计为违律）：
  - 第4句第4字「庭」：平仄两收且无据以定音的义项依据，按 UNKNOWN 处理（平仄两收：下平九青、去二十五径）
```

```
结论：不适用近体格律（韵脚全为仄声，当属古体或仄韵体）
· 按近体谱强行计算原本会产出 11 处判定，已全部作废、不列示。
```

## 五、六条结构不变量（可复跑的机器检查）

`engine/run_tests.py` 对 33 个用例逐例执行：

| 编号 | 不变量 | 检查什么 |
|---|---|---|
| I1 | 状态合法性 | 每个位置的状态必须在六种之内 |
| I2 | 谱长一致 | 展示谱长度 = 句长 |
| I3 | 位态对应 | 「示谱为『中』」⟺「状态为 FLEXIBLE」 |
| I4 | PASS 的读音前提 | 判 PASS 的字，读音必须唯一且等于正格 |
| I5 | 计数一致 | 有逐字 FAIL 就必须有违律记录；零违律不得判为违律 |
| I6 | 待确认计数 | 待确认条数与输出条数一致 |

I3 和 I4 正是 A04 的靶心：

- I3 保证「模板显示平声、结果打勾」这类矛盾**不可能通过测试**。
- I4 保证「用两读字凑出来的 PASS」**不可能通过测试**。

执行结果：**33 例，不变量违规 0 例**（`logs/independent_test_console.txt` 末段）。
I5 在首次运行时确实报过违规（古体样本，逐字 FAIL 因体制判定被作废），已按真实原因修正检查口径，
修正记录见 `09_代码修复记录.md`。
