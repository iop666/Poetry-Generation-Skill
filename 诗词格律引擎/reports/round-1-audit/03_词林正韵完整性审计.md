# 03 词林正韵完整性审计

**对应审核**：A02
**结论**：**成立。** v1 只有平声十四部，且把三个「半韵」整体塞进某一部（等于臆断）；本轮补足十九部结构与数据，
但**词林正韵的字级归属仍缺依据**，凡落在半韵中的字一律返回 UNKNOWN。**因此「完整支持词林正韵」这个说法仍然不成立，已从文档与报告中撤下。**

---

## 一、v1 的实际状态

`engine/gedou.py` v1 中的全部词韵数据就是 `CILIN_PING` 一个字典，30 条，形如：

```python
"十灰": "第三部",
"九佳": "第五部",
"十三元": "第六部",
```

三个问题：

| 问题 | 具体表现 | 后果 |
|---|---|---|
| 只有平声 | 无上、去、入声任何映射 | 仄韵词牌完全不能判；仄声韵脚一律报「出韵」 |
| 半韵被整体归部 | 十灰→第三部、九佳→第五部、十三元→第六部 | **把「不确定」写成了「确定」** |
| 无覆盖校验 | 没有任何自检 | 漏一个韵目不会报错 |

### 1.1 半韵臆断造成的实际错误

《词林正韵》把「十灰」按**字**分入第三部与第五部：

- 第三部收「回、雷、梅、杯、催、堆」一类（-ui/-ei）
- 第五部收「来、台、开、才、栽、哀」一类（-ai）

v1 把整个十灰判给第三部，于是「来」被当成第三部字。后果是双向的：

- **漏判**：一首词押「来（实为第五部）＋时（第三部）」，v1 认为同部，判合格 —— 实为出韵。
- **误判**：一首词押「来＋台」（同为第五部），v1 也认为同部，判合格 —— 结论对，但理由错。

即：**结论碰巧对的时候，推理是错的**。这比单纯判错更难发现。

## 二、本轮改动

### 2.1 十九部结构补全

新增 `engine/cilin.py`，按戈载《词林正韵》十九部建表：

| 声调 | 韵目数 | 对应部 |
|---|---|---|
| 平声 | 30 | 第一–第十四部 |
| 上声 | 29 | 第一–第十四部 |
| 去声 | 30 | 第一–第十四部 |
| 入声 | 17 | 第十五–第十九部 |
| **合计** | **106** | 与平水韵韵目数一致 |

自检（`engine/cilin.py` 内置，`tools/build_cilin.py` 调用）：

- 部号必须恰为 {1…19}；
- 韵目数必须恰为 106；
- 平／上／去／入 四类必须齐备；
- 19 部每部必须有说明。

三条全部通过。生成数据见 `诗歌知识库/04_韵书/词林正韵_十九部.json`，人读表见同名 `.md`。

### 2.2 覆盖校验

把索引中全部 `(声部, 韵目)` 与十九部表对撞，未覆盖项为 **0**。

（过程中的真实故障：源表韵目为繁体且有异名 ——「二十八琰」「二十一箇」「十七筿」；
初次对撞出现 39 个未覆盖项。加入韵目归一（琰→俭、箇→个、筿→筱）后归零。
这类问题不修，就会在「看起来支持」的表象下静默失败。）

### 2.3 半韵：从「臆断」改为「UNKNOWN」

`HALF_RHYMES` 共 9 个韵目：十灰、九佳、十三元、十贿、十三阮、九泰、十卦、十一队、十四愿。

引擎对落在此范围内的字返回**两个候选部**且置 `ambiguous=True`，词韵判定时：

```
? 第2句韵脚「回」属半韵（候选部 [3, 5]），《词林正韵》按字分属两部，
  本项目缺字级依据，未作判定
```

量化影响：

| 指标 | 数值 |
|---|---|
| 半韵涉及唯一字数 | 692 |
| 落在半韵中的读音记录 | 773 / 10493（7.4%） |
| 十灰单韵字数 | 113 |

也就是说，**每 13 个韵字里就有约 1 个，本引擎无法判定其词韵归属**。这是必须写明的能力上限。

### 2.4 平声覆盖统计（审核要求的「明确子集」）

| 项 | v1 | v2 |
|---|---|---|
| 收部数 | 14（平声） | 19（平上去入） |
| 收韵目数 | 30 | 106 |
| 半韵处理 | 整体归部（臆断） | 候选两部 + UNKNOWN |
| 覆盖自检 | 无 | 有，未覆盖项 0 |
| 字级归属数据 | 无 | **仍无** |

## 三、仄韵词牌支持状态（审核要求「检查」）

**结论：不支持，但数据已备。**

| 项 | 状态 |
|---|---|
| 仄声部（上/去/入）数据 | 已具备（第十五–第十九部为入声，上/去声各归十四部） |
| 仄声韵脚查部能力 | 已具备（`Lexicon.cilin(ch, "仄")`） |
| 仄韵词牌词谱 | **未收**，故无法校验 |
| 现有三个词牌 | 浣溪沙（平韵）、忆江南（平韵）、相见欢（上片平韵＋下片两仄韵，仄韵位标未检查） |

为什么不在本轮补仄韵词牌：补谱必须逐字有据（参见 A01 的教训）。《钦定词谱》对多数仄韵词牌只给例词平仄，
不给中谱；没有可靠底本而先加词牌，等于复制第二个 A01。**故本轮只备数据、不加谱，并在报告中登记缺口。**

## 五、结论

- 「已支持词林正韵」这一说法 **不成立**，v1 报告与 README 中的相关表述已改。
- 现在可以说的是：**十九部结构与韵目映射完整、可自检；平韵词牌可判；半韵与仄韵词牌不可判，且引擎会明说不可判。**
- 这一条只能给 `PARTIAL`，不能给 `RESOLVED`。理由：数据层级从「平声 14 部」升到「十九部 106 韵」，但**字级归属仍然缺失**，而字级归属才是词韵判定的真正依据。
