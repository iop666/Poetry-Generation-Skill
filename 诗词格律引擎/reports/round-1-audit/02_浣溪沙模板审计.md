# 02 浣溪沙模板审计

**对应审核**：A01
**结论**：**成立。v1 模板确有错误，已改正。** 同时发现变体管理缺失、并连带查出「相见欢」词谱也有错（见 B04）。

---

## 一、审核意见

> 搜韵《钦定词谱》中韩偓正体第一句的格式是 `中仄中平中仄平`，而当前报告展示的是 `中仄平平中仄平`。第三字的规则存在差异。

## 二、核验过程

### 2.1 取得的原始文献文字

检索到的《钦定词谱》浣溪沙条（转录自清·王奕清等《钦定词谱》，中国书店 2010 年影印本）原文：

> 浣溪沙　双调四十二字，前段三句三平韵，后段三句两平韵　韩偓
> 宿醉离愁慢髻鬟　六铢衣薄惹轻寒　慵红闷翠掩青鸾
> **中仄中平中仄平韵　中平中仄仄平平韵　中平中仄仄平平韵**
> 罗袜况兼金菡萏　雪肌仍是玉琅玕　骨香腰细更沈檀
> **中仄中平平仄仄句　中平中仄仄平平韵　中平中仄仄平平韵**
> 此调以此词为正体，若薛词之少押一韵，孙词、顾词之摊破句法，李词之换仄韵，皆变体也。

两处独立来源文字一致：

| 来源 | 内容 | 状态 |
|---|---|---|
| 查格律（chagelv.com）「浣溪沙词谱」，注明「资料引用自《钦定词谱》」 | 第一句 `中仄中平中仄平` | READ |
| 诗词名句网「浣溪沙（钦谱）」 | 第一句 `中仄中平中仄平` | READ |
| 维基百科「浣溪沙」条（引《钦定词谱》） | 正体作「仄仄平平仄仄平」，未标「中」 | READ（仅作旁证，不作依据） |

> 本项目只取「谱字」这一事实性内容，不引用其注释文字。

### 2.2 v1 与文献的差异

| 句 | v1 谱 | 《钦定词谱》 | 差异 |
|---|---|---|---|
| 1 | `中仄平平中仄平` | `中仄中平中仄平` | **第 3 字：v1 作「平」，文献作「中」** |
| 2 | `中平中仄仄平平` | `中平中仄仄平平` | 一致 |
| 3 | `中平中仄仄平平` | `中平中仄仄平平` | 一致 |
| 4 | `中仄中平平仄仄` | `中仄中平平仄仄` | 一致 |
| 5 | `中平中仄仄平平` | `中平中仄仄平平` | 一致 |
| 6 | `中平中仄仄平平` | `中平中仄仄平平` | 一致 |

差异只有一处，方向是 **v1 比词谱更严**：把一个「可平可仄」的位置写成了「必须用平」。

### 2.3 影响面评估（不做夸大）

必须说明：**这一处在传世作品中极少被用到仄声**。

抽查 8 首名家浣溪沙，第一句第 3 字全部为平：

| 作者 | 首句 | 第 3 字 | 平仄 |
|---|---|---|---|
| 韩偓 | 宿醉离愁慢髻鬟 | 离 | 平 |
| 晏殊 | 一曲新词酒一杯 | 新 | 平 |
| 秦观 | 漠漠轻寒上小楼 | 轻 | 平 |
| 周邦彦 | 楼上晴天碧四垂 | 晴 | 平 |
| 李清照 | 莫许杯深琥珀浓 | 杯 | 平 |
| 纳兰性德 | 谁念西风独自凉 | 西 | 平 |
| 韦庄 | 夜夜相思更漏残 | 相 | 平 |
| 苏轼 | 山下兰芽短浸溪 | 兰 | 平 |

因此，这个错误的**实际后果是「理论上会误杀、实际上几乎不会触发」**，即：
它不会让好词被判坏，但会让引擎对一类合法词（第 3 字用仄）给出错误结论。
严重程度按「潜在误判」计为 P0，按「已发生的误判」计为低频。这个区分必须写明，不能借机渲染。

### 2.4 正反验证

新增样本 `tests/03_variants_legal.json` V03，构造一首合规的浣溪沙，第一句第 3 字用仄：

```
宿醉小窗夜气清，一灯明灭照孤城，旧书重理到三更。
露冷空庭人未寝，隔帘疏雨滴秋声，半床凉月伴残檠。
```

- 第 1 句「宿醉小窗夜气清」＝ 仄仄仄平仄仄平，第 3 字「小」为仄。
- 按《钦定词谱》`中仄中平中仄平`：第 3 字为中，**合法**。
- 按 v1 谱 `中仄平平中仄平`：第 3 字应平，**判出律**。

引擎实际输出（测试断言 `定点校验：第 1 句第 3 字状态 = FLEXIBLE`）：

```
 1  中仄中平中仄平  宿醉小窗夜气清  ●●●○●●○  ~✓~✓~✓✓
```

第 3 字判定为 `~`（FLEXIBLE，可平可仄），未计为违律。**反例证明修改生效。**

同时，v1 的正确部分必须保留：第 4 句 `中仄中平平仄仄` 与第 5、6 句 `中平中仄仄平平` 均无误，本轮未改。

## 三、变体管理

审核要求「检查变体管理」。核查结果：**v1 完全没有变体概念，只有一个硬编码谱**。

《钦定词谱》浣溪沙下列正体一、又一体四。本轮把变体登记进 `CI_VARIANTS`，但**只登记元数据、不提供可平可仄谱**：

| 变体 | 字数 | 特征 | 本轮处理 |
|---|---|---|---|
| 薛昭蕴体 | 42 | 首句不起韵 | 登记；《钦定词谱》仅例句词平仄，未归纳中谱，故不收谱、不校验 |
| 孙光宪体 | 44 | 后结作三字三句 | 登记；未收谱、不校验 |
| 顾夐体 | 46 | 前后结皆三字三句 | 登记；未收谱、不校验 |
| 李煜体 | 42 | 全押仄韵 | 登记；引擎尚无仄韵词谱，不校验 |

**为什么不收谱**：《钦定词谱》对「又一体」只给例词每字的平仄，不给「中」谱。
若把例词平仄直接当谱用，等于要求所有作者与该例词逐字相同 —— 这会把合法作品全部判错。
宁可不校验并明说，也不制造第二类 A01。

行为验证（`tests/06_cipai.json` C05，薛昭蕴「红蓼渡头秋正雨」）：
引擎按正体计算会报韵脚违律，同时在备注中输出

> 首句末字为仄声，与正体「首句起韵」不合；可能属薛昭蕴体（首句不起韵）。本引擎未收录其可平可仄谱，不做判定。

即：**判错时自己说明判错的可能原因**，而不是静默给出「不合格」。

## 四、连带发现：相见欢词谱也有错（B04）

核验浣溪沙时顺带复核了另两个已收词牌，发现「相见欢」错得更重：

| 项 | v1 | 《钦定词谱》 | 后果 |
|---|---|---|---|
| 句式 | 9 句：6/3/9/3/3/3/3/3/3 | **7 句：6/3/9/3/3/3/9** | 字数同为 36，但切分错位，任何合格词都会「句式不合」 |
| 上片第 2 句 | `中中仄` | `中平平` | 「月如钩」「太匆匆」为仄平平，v1 判第 3 字出律 |

已改正。验证样本 `tests/06_cipai.json` C04（李煜「无言独上西楼」）现判定 `待确认`、零违律。

修正后的谱：

```
中平中仄平平，中平平，中仄中平中仄仄平平。
中中仄，中中仄，仄平平，中仄中平中仄仄平平。
```

下片第 1、2 句押仄韵，本引擎无仄韵词谱，这两句的用韵标为未检查（`NOT_CHECKED` 语义），已在结果备注中说明。
