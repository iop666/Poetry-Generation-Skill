# 07 对仗审查报告

**对应审核**：A06
**结论**：**成立。** 审核要求「将结构相似度 100% 与对仗工整完全分开」。
本轮把指标改名为「词性位置一致率」，撤下「结构基本成对」这类结论，并明确本引擎不对仗打分。
但更严重的问题在数据层：词性小词典是手编的 345 字，**用它算出的比率没有格律学意义** —— 下面用杜甫《登高》证明。

---

## 一、v1 的表述问题

v1 对《秋日登楼》（自产七律）颔联／颈联的输出：

```
颔联：100%（6/6 字可比对）｜结构基本成对（词性/句法可复核）
  未定字对：随抱
颈联：100%（4/4 字可比对）｜结构基本成对（词性/句法可复核）
  未定字对：浮白、云发、足胜
```

三处问题：

1. **分母被悄悄缩小**。颔联七言两句共 14 字，只比对 6 字，另外 8 字标「未定」后不计入分母。
   「100%」的分母是 6，不是 14。读者看到的是 100%，看不到 6/6 之外还有 8 个字没算。
2. **「结构基本成对」是结论，不是指标**。它由 `score >= 60` 推出，没有格律学依据。
3. **「结构相似度」这个名字暗示了它不成立的东西**。词性类别重合率与对仗是否成立，是两回事。

## 二、v2 的改动

| 项 | v1 | v2 |
|---|---|---|
| 字段名 | 结构相似度 | **词性位置一致率** |
| 结论 | 结构基本成对（score ≥ 60） | **需人工复核（本引擎不判对仗工整）** |
| 分母 | 只算可比对字 | 保留，但显式写出「m/n 字可比对」 |
| 未定字对 | 列出 | 列出 |
| 附加说明 | 「不评价意境与工拙」 | 增加「词性同类不等于对仗成立，更不等于工整」 |

判定阈值已删除。**不再有任何「是否对仗」的自动结论。**

## 三、为什么这个词性词典算不出对仗（实证）

杜甫《登高》颔联：

```
无边落木萧萧下
不尽长江滚滚来
```

这是历代公认的对仗范本（「无边」对「不尽」、「落木」对「长江」、「萧萧」对「滚滚」、「下」对「来」，
词性、结构、意象、声调四层皆对）。

v2 的实际输出：

```
颔联：50%（2/4 字可比对）｜需人工复核（本引擎不判对仗工整）
  词性未定字对：边尽、萧滚、萧滚
```

**50%。** 原因是词典 345 字里没有「边」「尽」「萧」「滚」，四个字全判「未定」，
剩下 4 个字（落／长、木／江）里只对了 2 个。

也就是说：**引擎给杜甫最工的对仗打了 50 分，给执行方自己写的诗打了 100 分。**

这个对比说明的不是「执行方比杜甫强」，而是：

1. 词典覆盖不到的字一律记为「未定」并**从分母中剔除**，导致越生僻的句子越容易得高分；
2. 执行方写诗时用的词性直觉，与自编词典的收录范围同源 —— 自己写的字多半在词典里，名人名句里的字反而不在。

这是典型的自利偏差，而且是**结构性的**：只要词典由执行方编、样本由执行方选，这个偏差就消不掉。

## 四、因此本项只做什么、不做什么

**做**：

- 给出「词性位置一致率」这一**机械统计量**，供人快速看两句的对应位置是否同词性；
- 列出「未定字对」，指明哪些位置无法比对；
- 明确标注「需人工复核」。

**不做**：

- 不判断是否成对；
- 不判断工拙；
- 不用它作为「合格」的依据（对仗不参与 `判定` 的生成）。

## 五、词性词典的真实状况（必须披露）

| 项 | 数值／说明 |
|---|---|
| 收录字数 | 345 |
| 类别 | 名／动／形／虚／数（N/V/A/U/M）五类 |
| 来源 | 执行方手工编写 |
| 校验情况 | **未经任何权威词性标注集校验** |
| 一字多类 | 大量存在（如「空」兼名、形） |
| 覆盖率 | 未统计（这是缺陷，见下） |

**未统计覆盖率是明确的工作疏漏**：应该在报告里给出「本词典对《唐诗三百首》全集的字覆盖率为 X%」，
本轮没做。列入 ROUND 2。

## 六、对 T3 验收题的影响

v1 的 T3 备注写「颔联／颈联结构相似度 100%／100%」，被当作对仗合格的证据。
v2 已改为：

> 颔联/颈联词性位置一致率 100%／100%（一致率不等于对仗工整，须人工复核）

并且**不再把对仗结果计入判定码**。T3 的通过与否，只看格律。

## 七、结论

- 表述问题：`RESOLVED`（指标改名、结论撤下、阈值删除）。
- 数据问题：`OPEN`（词典手编、未校验、覆盖率未测）。
- 建议：在对仗这件事上，**要么用带标注的语料做真正的句法比对，要么就诚实地只做人工清单**。
  现在这个 345 字词典 + 比率的形式，容易被误读为「机器判了对仗」，弊大于利。
  是否保留本项，请审核者定夺。
