# 诗话摘录（鉴赏库 · 01）

> 只收「可以拿来当审稿标准」的句子，每条附一句用法。不追求全，只追求能用。

## 一、王国维《人间词话》

- **「词以境界为最上。有境界则自成高格，自有名句。」**
  用法：判断一首诗成立与否，先问有没有「境」——景与情是否合成一个可进入的空间。
- **「有造境，有写境，此理想与写实二派之所由分。」**
  用法：写景要能分「实录」与「重构」；抒情诗多半是造境，但材料必须来自写境。
- **「有我之境，以我观物，故物皆著我之色彩；无我之境，以物观物，故不知何者为我，何者为物。」**
  用法：「泪眼问花花不语」是有我之境；「采菊东篱下，悠然见南山」是无我之境。
- **「境界有大小，不以是而分优劣。」**
  用法：不必强求宏大；一首小绝写透一寸光阴，也成立。
- **「隔与不隔」：「池塘生春草」「空梁落燕泥」不隔；「谢家池上，江淹浦畔」则隔。**
  用法：判「套语」的利器——读者要不要先翻译一层才能感到？要，就是隔。
- **「诗人对宇宙人生，须入乎其内，又须出乎其外。」**
  用法：入乎其内才有真感受，出乎其外才有结构。

## 二、严羽《沧浪诗话》

- **「诗者，吟咏情性也。盛唐诸人惟在兴趣，羚羊挂角，无迹可求。」**
  用法：好诗的道理不在字面，落到「言外之意」。
- **「学诗者以识为主，入门须正，立志须高。」**
  用法：取法乎上——先读大家，别从网络古风入手。
- **「夫诗有别材，非关书也；诗有别趣，非关理也。」**
  用法：知识库是底子，不是诗句本身；不能靠检索拼诗。

## 三、其他常用

- **欧阳修《六一诗话》：「状难写之景，如在目前；含不尽之意，见于言外。」**
  用法：写景要「如在目前」（具体），抒情要「见于言外」（不点破）。
- **苏轼：「大略如行云流水，初无定质，但常行于所当行，常止于所不可不止。」**
  用法：结构标准——该停就停，绝句第四句尤其忌拖。
- **姜夔：「句中有余味，篇中有余意，善之善者也。」**
  用法：结尾留白。
- **叶燮《原诗》：「诗之基，其人之胸襟是也。」**
  用法：气格问题，非技术可救。
- **沈德潜：「诗贵性情，亦须论法。」**
  用法：性情与法度并重——正是本项目的立场：引擎管「法」，人管「性情」。

## 四、把诗话变成可执行检查（本项目的做法）

| 诗话标准 | 可执行检查 |
|---|---|
| 有境界 | 全诗是否有一以贯之的空间/时间线索？ |
| 不隔 | 是否出现需要「翻译」的套语堆叠？（反套路清单） |
| 言外之意 | 末句是否把情绪说尽？说尽即扣分 |
| 如在目前 | 是否有至少一个具体细节（声、色、触、动作）？ |
| 行于所当行 | 是否有与本诗无关的凑句？ |
| 余味 | 结尾是否留了一个未解的悬念/画面？ |

> 注意：这些检查**只能人工判定**，引擎不参与。方案原文也强调「格律合规 ≠ 好诗」。
