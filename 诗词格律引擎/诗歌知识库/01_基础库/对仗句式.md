# 对仗句式（基础库 · 02）

> 用途：写作时「按类取对」，避免临时凑句；审稿时区分「工对／宽对／不成对」。

## 一、对仗的四个层面

1. **词性**：名对名、动对动、形对形、虚对虚、数对数。这是底线。
2. **结构**：主谓对主谓、动宾对动宾、偏正对偏正、并列对并列。
3. **平仄**：出句与对句对应位置平仄相反（这是律诗的要求，词可以不严）。
4. **意义**：相关而不相同。**忌合掌**（两句说同一件事，如「独坐」对「孤眠」）。

## 三、句式模板（七言 · 2-2-3 节奏）

按节奏切三段，每段内部词性对齐：

| 模板 | 出句 | 对句 |
|---|---|---|
| 名名·动名·形 | 千峰落叶随鸿尽 | 一水寒烟抱郭流 |
| 形名·形名·动 | 寒山古木风初急 | 野渡扁舟雨未收 |
| 数量·动名·名 | 一帘疏雨湿清秋 | 半榻寒灯照白头 |
| 形名·副动·动 | 孤城落日低还见 | 远水寒潮去不归 |
| 动名·动名·名 | 抱琴野寺寻僧话 | 载酒江楼送客归 |

> 注意：**同一联的句法结构不要与另一联雷同**，否则犯「四平头」「摞眼」。

## 四、对仗的三档

- **工对**：同类词相对，且小类也相对（天文对天文、器物对器物）。如「两个黄鹂鸣翠柳，一行白鹭上青天」。
- **宽对**：大类相对即可（名词对名词、动宾对动宾）。日常写作以宽对为主。
- **流水对**：上下句意思相承、不可分割，如水顺流而下。如「即从巴峡穿巫峡，便下襄阳向洛阳」。
  流水对不算「合掌」，反而是高格。

## 五、审稿清单

1. 每一联是否同字数、同节奏？
2. 每个对应位置是否同类词？（引擎给相似度与未定字对）
3. 两句是否说了同一件事（合掌）？
4. 中二联的句法结构是否雷同（四平头／摞眼）？
5. 有没有「重字」占了对应位置却没形成对？
