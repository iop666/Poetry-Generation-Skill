# 意象词典（基础库 · 03）

> 目的不是提供「漂亮词」，而是提供**意象的语义坐标**：它出现时带什么情绪、常与什么搭配、
> 在什么位置最有效，以及**如何避免套路**。写作时先定情绪坐标，再取象；不要反过来堆词。

## 一、意象的三层结构

1. **物象**（看得见）：月、雁、舟、砧、灯。
2. **情境**（物象所在的场）：月落、雁断、孤舟、寒砧、残灯。
3. **情思**（由情境逼出）：思归、迟暮、离恨、羁旅、无常。

好的句子三层同时到位；差的句子只有第一层在堆砌。

## 二、常用意象坐标表

| 意象 | 常见情绪 | 有效搭配 | 滥用风险 |
|---|---|---|---|
| 月 | 思乡、怀人、永恒对照短暂 | 床前／江心／戍楼／关山 | 「明月」开头即俗 |
| 雁（鸿） | 音书、羁旅、时序 | 归鸿、断雁、雁字、传书 | 与「相思」直接连写即俗 |
| 舟 | 漂泊、送别、归隐 | 孤舟、扁舟、客舟、归舟 | 「一叶孤舟」已成语套 |
| 砧（杵） | 秋夜、思妇、征人 | 寒砧、暮砧、万家砧 | 现代读者隔膜，宜少用 |
| 灯 | 孤夜、读书、迟归 | 残灯、寒灯、一灯 | 与「孤影」连用即俗 |
| 柳 | 送别、挽留 | 折柳、柳岸、柳色 | 「柳絮」滥于伤春 |
| 菊 | 高洁、迟暮、重阳 | 东篱、黄花、霜菊 | 直引陶渊明易空 |
| 梧桐 | 秋、孤寂、雨夜 | 疏雨梧桐、桐叶 | 与「细雨」固定搭配僵化 |
| 西风 | 秋、衰飒、肃杀 | 西风残照、西风紧 | 满篇西风则无骨 |
| 烟 | 朦胧、距离、时间 | 寒烟、暮烟、烟水 | 易成模糊填充词 |
| 关塞 | 边功、征戍、苍茫 | 玉关、阳关、塞云 | 无实感则空喊 |
| 钟/磬 | 警醒、时间、空寂 | 夜半钟、疏钟 | 与「客船」连用已成名句包袱 |
| 酒 | 遣怀、饯别、放达 | 浊酒、浊醪、一杯 | 只作情绪标签则弱 |
| 白发 | 迟暮、功业未成 | 白发、霜鬓 | 与「功名」连用易套 |
| 苔/草 | 荒废、幽居、时间 | 苍苔、荒草、芳草 | 「芳草萋萋」宜避 |
| 水（流） | 时间、无常、去而不返 | 东流、逝水、江水 | 「似水流年」已成词 |

## 三、意象组合的四条原则

1. **一诗一主象**：全篇围绕一个核心物象展开（如《秋山》以「望」为线，山、烟、鸿、斜阳层层推远）。
2. **虚实相生**：实（景）与虚（情、回忆、想象）交替。全实则板，全虚则空。
3. **动静相形**：静景中放一个动字（「烟初起」「叶踏来声」），全篇才活。
4. **由近及远或由远及近**：空间要有秩序，不要一句山一句楼一句心里。

## 四、反套路清单（方案「四」的告诫）

> 「不要让 AI 把所有古典诗词都写成满篇的『明月、清风、孤舟、落花、相思』。」

审稿时逐条打勾：

- [ ] 是否出现了 3 个以上的「万能意象」（月、风、舟、花、酒、愁）而无具体场景？
- [ ] 是否有至少一个**只属于这首诗**的细节（时间、地点、动作、声音、气味、触感）？
- [ ] 情绪是不是「说」出来的（愁、恨、思、泪）而不是「逼」出来的？
- [ ] 有没有把两个不搭的意象硬拼（如「铁马」＋「杏花」）？
- [ ] 结尾是否只是重复开头的情绪，而没有推进或转折？

## 五、细化到「可写」的例子

| 平庸写法 | 具体化改写 | 增益 |
|---|---|---|
| 秋风吹落叶 | 半庭黄叶踏来声 | 加了动作与听觉，现场感出来 |
| 夜里思家乡 | 只把寒灯剪到明 | 用一个通宵的具体动作代替「思」 |
| 江上送朋友 | 孤帆影没暮潮流 | 以「影没」收束，不写「不舍」 |
| 月亮很亮 | 清辉夜半满归舟 | 用「满」写光的量与范围 |
