# 格律规则（基础库 · 01）

> 依据：王力《诗词格律》《汉语诗律学》、龙榆生《唐宋词格律》。本文件是「可执行规则」的文字版，
> 与 `engine/gedou.py` 一一对应，规则条目后标注引擎中的检查名。

## 一、四声与平仄

中古四声：**平、上、去、入**。平声为「平」，上、去、入为「仄」。

- 平声分「上平」「下平」各十五韵，共三十平声韵。
- 入声在现代普通话中已派入四声（如「白、石、竹、独、夕」今读平声而古属仄），
  **这是今人写诗最易出错处，必须以韵书为准，不能凭普通话声调判断**。
- 多音字（如「过」平声歌韵 / 去声个韵，「看」平声寒韵 / 去声翰韵）按语境择读，
  引擎对多读字自动放宽（检查名：`多读放宽`）。

## 二、律句四式（七言）

| 代号 | 句式 | 平仄 | 特征 |
|---|---|---|---|
| A | 平收·仄起 | 仄仄平平仄仄平 | 押韵句 |
| B | 平收·平起 | 平平仄仄仄平平 | 押韵句 |
| C | 仄收·平起 | 平平仄仄平平仄 | 白脚 |
| D | 仄收·仄起 | 仄仄平平平仄仄 | 白脚 |

五言四式为其「去首二字」：甲 仄仄平平仄 / 乙 平平仄仄平 / 丙 平平平仄仄 / 丁 仄仄仄平平。

四条基本组合规律（王力）：
1. 一句之内，平仄相间（二四六分明）。
2. 一联之内，出句与对句平仄相对（**对**）。
3. 联与联之间，下联出句与上联对句第二字平仄相同（**粘**）。
4. 押韵句必须平收，白脚必须仄收。

## 三、四种起式（以七绝为例）

| 起式 | 句式序 | 首句 |
|---|---|---|
| 仄起首句入韵 | A B C A | 押韵 |
| 仄起首句不入韵 | D B C A | 白脚 |
| 平起首句入韵 | B A D B | 押韵 |
| 平起首句不入韵 | C A D B | 白脚 |

律诗为绝句的延长：仄起入韵 = A B C A D B C A，其余类推（引擎 `TEMPLATES`）。
词牌另立谱（引擎 `CI_PATTERNS`），以「中」表示可平可仄。

## 四、一三五不论与它的边界

七言第一、三、五字，五言第一、三字，一般可不论。但有三条例外，引擎单独检查：

1. **孤平**：韵句（平收句）中除韵脚外只剩一个平声字。如「仄仄仄平仄仄平」。
   救法：把该平声字前后的仄改为平，或将第五字改平（本句自救）。
   检查名：`孤平`。
2. **三平调**：韵句末三字全平。古诗中极罕见，近体视为大病。
   检查名：`三平调`。
3. **三仄尾**：白脚末三字全仄。比三平调宽，但仍是瑕疵。检查名：`三仄尾`（提示级）。

## 五、押韵

- 近体诗一般只押**平声韵**，一韵到底，不得通押（除首句可借邻韵，称「孤雁出群格」）。
- 韵脚须同属平水韵一个韵部。出韵即「落韵」，不合格。检查名：`押韵 / 出韵`。
- 白脚不得用与韵脚同韵部的字，否则「撞韵」。检查名：`撞韵`（提示级）。
- 忌「重韵」（同一韵字重复使用）；忌「重字」（非有意复沓的重复字）。
  检查名：`重字`（提示级）。

## 六、对仗

- 律诗**颔联（三四句）、颈联（五六句）必须对仗**；绝句可对可不对。
- 要求：字数相等、词性相当、结构相应、平仄相对、意义相关而不重复（忌「合掌」）。
- 引擎做「结构粗检」：按 2-2-3 节奏逐字比对词性类别，给出相似度并列出未定字对，
  **不评价工拙与意境**。检查名：`对仗（结构粗检）`。

## 七、章法

近体诗讲「起、承、转、合」：
起句点题或造境；承句展开、落实；转句换笔（换空间、换时间、换视角、由景入情）；合句收束、宕开、留余味。
律诗则「首联起、颔联承、颈联转、尾联合」，中间两联写景叙事，尾联抒情议论。
