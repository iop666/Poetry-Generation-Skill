# 七言绝句 · 秋望（豪放）

```
万里西风卷大荒，长河一线走苍茫。男儿莫洒临歧泪，且向天涯拓土疆。
```

## 创作说明

- 笔法：以大取势——「万里」「大荒」「长河一线」，用尺度制造气魄。
- 动词：卷、走、拓，三个动作都带外力，句子因此不软。
- 转折：第三句「莫洒」是止泪，第四句「且向」是转身，把送别的低落改写成出发。
