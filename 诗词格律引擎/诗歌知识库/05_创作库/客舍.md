# 七言绝句 · 客舍（重构稿）

```
客舍秋深雨乍晴，半庭黄叶踏来声。无人共说家山事，只把寒灯剪到明。
```

## 创作说明

- 原稿病在：全是「秋风／落叶／思乡／明月」四件套，情绪靠「思乡」二字硬说，无一个只属于这首诗的细节。
- 重构手段一（具体化）：把「秋风凋碧树」换成「半庭黄叶踏来声」——加上脚步与声音，秋夜有了人的动作。
- 重构手段二（动作代情绪）：删去「思乡」二字，改「只把寒灯剪到明」——用一个通宵剪灯芯的动作代替「睡不着」。
- 重构手段三（时间与空间落地）：「客舍秋深雨乍晴」先给地点、季节、天气，读者才能站进去。
- 结果：意象仍是旧的（叶、灯、雨），但因组合与细节是新的，不再是一首可以套给任何人的仿古诗。
