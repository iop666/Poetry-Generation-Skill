# 七言绝句 · 秋望（清远）

```
一江秋水澹无愁，远岫微茫入暮流。散尽沙鸥烟未起，清辉夜半满归舟。
```

## 创作说明

- 笔法：以「澹」「微茫」「未起」写疏淡，全篇不作强烈情绪，只给一个空阔的江面。
- 着色：秋水、远岫、沙鸥、烟、清辉——五样东西都是「淡」的，互相不争。
- 落点：「满归舟」把光写成可以盛满的东西，是全诗唯一的重笔。
