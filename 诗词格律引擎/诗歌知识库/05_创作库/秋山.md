# 七言绝句 · 秋山

```
山色苍茫暮雨收，寒烟一带过汀洲。归鸿不解人间意，犹向斜阳万里游。
```

## 创作说明

- 取象：山、雨、烟、汀洲、归鸿、斜阳——全部服从一个「望」的动作，由近（山色）到远（斜阳）。
- 结构：一句写雨后山色，二句写江上寒烟，三句换到天上归鸿并「转」出人事，四句以「犹向」宕开。
- 用意：鸿雁不懂人间的意思，仍旧朝着斜阳飞过万里——把「不解」与「犹向」对举，情绪不点破。
