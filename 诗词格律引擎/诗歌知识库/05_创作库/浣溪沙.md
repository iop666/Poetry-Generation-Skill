# 浣溪沙 · 秋江送别

```
一曲离歌送客舟，西风落叶满江秋，寒烟衰草锁汀洲。别后相思何处寄，楚天无际两悠悠，孤帆影没暮潮流。
```

## 创作说明

- 上片写送别现场：离歌—客舟—落叶—寒烟，视线由人推向江面，再由江面推到汀洲。
- 下片转写别后：先设问「何处寄」，再以「楚天无际」拉开空间，末句用「影没」收束，不写不舍。
- 用韵：舟、秋、洲、悠、流，词林正韵第十二部，一韵到底。
