# 七言绝句 · 秋望（婉约）

```
残香轻袅锁清愁，独倚危阑数去舟。雁字不回桐叶老，一帘疏雨到深秋。
```

## 创作说明

- 笔法：从室内残香起笔，推到楼头危阑，再落到窗外雁字、桐叶、疏雨，空间由内而外。
- 含蓄：「数去舟」的「数」字把等待写成动作，「锁清愁」的「锁」把情绪关在室内。
- 末句：「到深秋」三字把一场雨写成一整个季节的抵达，不作哀语。
