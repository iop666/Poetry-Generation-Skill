# 七言律诗 · 秋日登楼

```
独上高楼望九州，长空万里送残秋。千峰落叶随鸿尽，一水寒烟抱郭流。世事浮云何足问，生涯白发不胜愁。唯应痛饮酬佳节，莫负东篱半亩幽。
```

## 创作说明

- 章法：首联登楼望远（起），颔联写景（承），颈联由景入情（转），尾联以「痛饮」「东篱」作结（合）。
- 对仗：颔联「千峰／一水、落叶／寒烟、随鸿尽／抱郭流」；颈联「世事／生涯、浮云／白发、何足问／不胜愁」。
- 用韵：州、秋、流、愁、幽，下平十一尤，一韵到底，无重字（「风」字原在二、三句重复，已改「长空」避之）。
