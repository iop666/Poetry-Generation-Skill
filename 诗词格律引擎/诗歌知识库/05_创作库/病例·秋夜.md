# 病例 · 秋夜（故意写坏，用于测错）

```
独坐小窗夜气清，一灯明灭照孤城。旧约难忘空叹息，露冷空庭生秋风。
```

## 说明

- 本首为「测错样本」，故意在第1、3、4句埋入五类格律病：孤平、失粘失对、出律、三平调、落韵。
- 用途：验证引擎能否一次报出全部错误，而不是只报第一条。

    - 第3句第2字「约」应为平声，实为仄声（出律）
    - 第4句第6字「秋」应为仄声，实为平声（出律）
    - 韵脚不协：共出现 一东、八庚 等不同韵部，属「出韵（落韵）」
    - 第3、4句第二字「约」「冷」平仄相同，失对
    - 第2、3句第二字「灯」「约」平仄相反，失粘
    - 第1句除韵脚外仅「窗」一字为平声，犯「孤平」
    - 第4句句末「生秋风」三字全平，犯「三平调」

  ? 待人工确认（未计为通过，也未计为违律）：
    - 第4句第4字「庭」：平仄两收且无据以定音的义项依据，按 UNKNOWN 处理（平仄两收：下平九青、去二十五径）
    - 第3句句末「空叹息」是否三仄尾，因读音未定无法判定
  ! 重字：空×2（有意复沓可忽略）
  · 若此作为古体（不守近体平仄），本判定不适用。

  结论：不合近体格律（7 处）
