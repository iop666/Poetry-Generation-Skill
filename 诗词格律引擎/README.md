# 诗词格律引擎 · 项目说明（v2，ROUND 1 整改后）

按「AI 要有知识体系、要有格律审查、不能只靠语感」的思路做的**可运行**的诗词写作辅助系统：
知识库（规则 + 韵书 + 作品）＋ 格律审查引擎（可判定部分）＋ 独立测试集。

> **v2 与 v1 的关系**：v2 是对 v1（2026-11-09 交付）的可信度整改。
> v1 存在「多音字按格律选音」「逐字表把不论位记为通过」「孤平规则误施」「古体被套近体谱」
> 等问题，曾把杜甫《春望》、苏轼《饮湖上初晴后雨》判错。
> 整改内容见 `reports/round-1-audit/`，v1 的自我评价不再适用。

## 快速开始

```bash
# 校验一首诗（自动判体式、逐字平仄、粘对、押韵、孤平、三平调、重字、对仗粗检）
python3 engine/gedou.py --title "秋山" \
  --text "山色苍茫暮雨收，寒烟一带过汀洲。归鸿不解人间意，犹向斜阳万里游。"

# 校验一首词
python3 engine/gedou.py --cipai 浣溪沙 --title "秋江送别" \
  --ci "一曲离歌送客舟，西风落叶满江秋，寒烟衰草锁汀洲。别后相思何处寄，楚天无际两悠悠，孤帆影没暮潮流。"

# 独立测试集（33 例，样本先于结论存在）
python3 engine/run_tests.py

# 六道验收题（自测，不能替代独立测试集）
python3 engine/run_acceptance.py

# 重建韵书索引 / 词林正韵数据
python3 tools/build_lexicon.py
python3 tools/build_cilin.py
```

退出码：`0` = 未发现明确违律（含「待确认」与「不适用」），`2` = 存在违律。

## 四种判定码

| 判定 | 含义 |
|---|---|
| `合格` | 全部位置读音确定且合律 |
| `待确认` | 未发现违律，但有读音/韵部无法确定的位置（输出中逐条列出） |
| `违律` | 有确定违律 |
| `不适用` | 非近体（如仄韵古体），不套近体谱 |

**`待确认` 不等于合格。** 引擎明确拒绝为读音未定的字选音，这类位置一律输出 `UNKNOWN`。

## 引擎能力边界

| 能判 | 不判（输出「待确认」或「需人工复核」） |
|---|---|
| 出律（固定位：七言 2/4/6/7 字，五言 2/4/5 字） | 多音字的义项定音（无表即 UNKNOWN） |
| 失对、失粘 | 借邻韵（孤雁出群格） |
| 落韵／出韵、白脚平收 | 撞韵 |
| 孤平（仅两平相连型平收句）、三平调、三仄尾 | 半韵字的词韵归属 |
| 重字、句式字数、词牌谱（3 个词牌） | 仄韵词牌的谱 |
| 古体／仄韵体识别（偶句韵脚全仄） | 平韵古体（如《静夜思》，会被判不合近体） |
| 特拗（鲤鱼翻波）识别 | 对仗是否成立、工拙 |
| 词林正韵十九部查部 | 文学性评分 |

## 依赖

- Python 3.9+
- 仅 `tools/build_lexicon.py` 需要 `opencc-python-reimplemented`（繁简转写，一次性）
- 引擎本身**零第三方依赖**，只读本地 JSON

## 已知局限（如实列出）

1. **多音字不消歧**：白名单外一律 `UNKNOWN`。测试集统计 28 字 48 处（`logs/polyphone_pending.md`）。
2. **词林正韵缺字级归属**：半韵 9 个韵目、692 字无法判定，只能报 `UNKNOWN`。
3. **词牌仅 3 个**，且无仄韵词牌；浣溪沙的四个变体只登记不收谱。
4. **对仗不做判定**：只给「词性位置一致率」，词性词典为手编 345 字，未经校验。
5. **平韵古体不能识别**：仅能识别仄韵体。
6. **韵书来源未核验**：源表出处不明，874 个两读字中真又音与数据噪声无法区分。
7. **文学性不进引擎**：只给清单式自查（诗话摘录最后一节）。
